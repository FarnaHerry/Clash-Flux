核心特性

Clash YAML 编译 & 原生直通

支持 Clash 订阅（YAML/节点链接）、sing-box 原生 JSON 与 OpenVPN，自带完整转换器与保真度账本，显式记账不静默丢规则。

独立特权网络服务

Linux systemd / Windows SCM 托管 sing-box、TUN 与系统 PPTP，系统目录安装后随软件更新自动静默自升级服务，无需反复弹窗。

多订阅编排与规则追溯

支持桌面跨订阅选择策略目标、全局与个人规则覆写、连接规则追溯，以及网站出口测试与 QiFi/QRS 多帧二维码分享。

现代原生界面与主题

HuxerUI 原生渲染，支持深浅模式、Gemini 多色渐变、OKLCH 自适应自定义配色，以及应用内版本检查与完整性校验。

一键安装

Linux / macOS（Linux 自动校验公钥指纹、配置本签名 APT/RPM 软件源并装入 /opt/clash-flux；macOS 自动安装 .dmg 至 /Applications）：

curl -fsSL https://github.com/FarnaHerry/Clash-Flux/releases/latest/download/install.sh | sh

Windows PowerShell（校验 SHA-256 后默认运行官方 .exe 安装包）：

irm https://github.com/FarnaHerry/Clash-Flux/releases/latest/download/install.ps1 | iex

卸载命令（默认保留本地配置与订阅）：Linux / macOS 执行 install.sh --uninstall，Windows 执行 install.ps1 -Uninstall。

Linux 签名软件源信息

  • APT 仓库：https://farnaherry.github.io/Clash-Flux/apt（suite: stable，component: main，支持 amd64 / arm64）
  • RPM 仓库：https://farnaherry.github.io/Clash-Flux/rpm/$basearch（支持 x86_64 / aarch64）
  • GPG 公钥（ASCII / RPM）：gpg.key · clash-flux.gpg（APT keyring）
  • 公钥指纹：{{GPG_FINGERPRINT}}
查看手动配置 Debian / Ubuntu (APT) 与 Fedora / RHEL (RPM) 命令 
# Debian / Ubuntu (amd64 & arm64)
sudo mkdir -p /usr/share/keyrings /etc/apt/sources.list.d
curl -fsSL https://farnaherry.github.io/Clash-Flux/clash-flux.gpg | sudo tee /usr/share/keyrings/clash-flux.gpg >/dev/null
sudo tee /etc/apt/sources.list.d/clash-flux.sources <<EOF
Types: deb
URIs: https://farnaherry.github.io/Clash-Flux/apt
Suites: stable
Components: main
Architectures: $(dpkg --print-architecture)
Signed-By: /usr/share/keyrings/clash-flux.gpg
EOF
sudo apt update && sudo apt install -y clash-flux
# Fedora / RHEL (x86_64 & aarch64)
sudo rpm --import https://farnaherry.github.io/Clash-Flux/gpg.key
sudo tee /etc/yum.repos.d/clash-flux.repo <<'REPO'
[clash-flux]
name=Clash-Flux
baseurl=https://farnaherry.github.io/Clash-Flux/rpm/$basearch
enabled=1
gpgcheck=1
repo_gpgcheck=0
gpgkey=https://farnaherry.github.io/Clash-Flux/gpg.key
REPO
sudo dnf install -y clash-flux

Debian / Ubuntu 后续可直接通过 sudo apt update && sudo apt upgrade 升级；Fedora / RHEL / openSUSE 可直接通过 sudo dnf upgrade 或 sudo zypper up 升级。Arch 等其他发行版可在 Releases 下载 .tar.gz 并解压至 /opt/clash-flux。
