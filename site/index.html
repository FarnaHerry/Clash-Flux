安装与软件源

Linux 自动校验公钥指纹、配置本签名 APT/RPM 软件源并装入 /opt/clash-flux；macOS 自动安装 .dmg 至 /Applications：

curl -fsSL https://github.com/FarnaHerry/Clash-Flux/releases/latest/download/install.sh | sh

卸载（默认保留本地配置与订阅）：curl -fsSL https://github.com/FarnaHerry/Clash-Flux/releases/latest/download/install.sh | sh -s -- --uninstall

APT（amd64 / arm64，suite: stable）：https://farnaherry.github.io/Clash-Flux/apt · RPM（x86_64 / aarch64）：https://farnaherry.github.io/Clash-Flux/rpm/$basearch

GPG 公钥指纹：{{GPG_FINGERPRINT}} · gpg.key · clash-flux.gpg

查看手动配置 Debian / Ubuntu (APT) 与 Fedora / RHEL (RPM) 命令 
# Debian / Ubuntu (amd64 & arm64)
sudo mkdir -p /usr/share/keyrings /etc/apt/sources.list.d
curl -fsSL https://farnaherry.github.io/Clash-Flux/clash-flux.gpg | sudo tee /usr/share/keyrings/clash-flux.gpg >/dev/null
sudo tee /etc/apt/sources.list.d/clash-flux.sources <<EOF
Types: deb
URIs: https://farnaherry.github.io/Clash-Flux/apt
Suites: stable
Components: main
Architectures: $(dpkg --print-architecture)
Signed-By: /usr/share/keyrings/clash-flux.gpg
EOF
sudo apt update && sudo apt install -y clash-flux
# Fedora / RHEL (x86_64 & aarch64)
sudo rpm --import https://farnaherry.github.io/Clash-Flux/gpg.key
sudo tee /etc/yum.repos.d/clash-flux.repo <<'REPO'
[clash-flux]
name=Clash-Flux
baseurl=https://farnaherry.github.io/Clash-Flux/rpm/$basearch
enabled=1
gpgcheck=1
repo_gpgcheck=0
gpgkey=https://farnaherry.github.io/Clash-Flux/gpg.key
REPO
sudo dnf install -y clash-flux

在 PowerShell 中自动校验 SHA-256 并安装官方安装包（默认运行 WiX 安装包以支持 Windows SCM 系统服务托管）：

irm https://github.com/FarnaHerry/Clash-Flux/releases/latest/download/install.ps1 | iex

支持参数：-Passive（静默进度）、-Portable（免安装便携版）、-Uninstall（卸载）。

配置软件源后即可随系统更新自动升级 Clash-Flux；Arch 等其他发行版可从 Releases 下载 .tar.gz 并解压至 /opt/clash-flux：

# Debian / Ubuntu
sudo apt update && sudo apt upgrade

# Fedora / RHEL
sudo dnf upgrade --refresh

# openSUSE
sudo zypper refresh && sudo zypper up

核心特性

Clash YAML 编译 & 保真度账本

支持 Clash YAML 订阅、节点链接、sing-box 原生 JSON 与 OpenVPN，内置完整转换器按 exact / approx / unsupported 显式记账。

独立特权网络服务

Linux systemd / Windows SCM 托管 sing-box、TUN 与系统 PPTP，装入系统目录后随软件更新静默自升级服务。

多订阅编排与规则追溯

支持桌面跨订阅选择策略目标、全局与个人规则覆写、连接规则追溯、网站出口测试与 QiFi/QRS 多帧二维码分享。

现代原生界面与主题

HuxerUI 原生渲染，支持深浅模式随系统同步、Gemini 多色渐变、OKLCH 自适应自定义配色与低内存托盘模式。

全平台覆盖 & 单实例架构

覆盖 Linux、Windows、macOS 与 Android，GUI/CLI 共用单实例运行时与数据库路径，兼顾桌面响应速度与移动后台托管。

签名软件源 & 完整性校验

内置应用内版本检查与哈希校验，官方 APT / RPM 仓库使用独立 RSA-4096 公钥签名元数据与安装包，安装升级全程可验证。
