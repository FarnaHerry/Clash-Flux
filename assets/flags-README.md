Windows country flag artwork
============================

`flags.png` is a 16-column atlas of 48 × 36 pixel flags. `flags.codes` lists
the corresponding lowercase two-letter codes in atlas order, separated by
spaces. The application uses these only for display on Windows; subscription
text and sing-box tags keep their original UTF-8 regional-indicator sequences.

Source: [flag-icons](https://github.com/lipis/flag-icons), `flags/4x3/*.svg`
at commit `ac7e0eb3259eb62aa6100c435607e2fe03896a97` (two-letter files).
Artwork is distributed under the MIT license in `flags-LICENSE.txt`.
The SVG files were rasterized to 48 × 36 pixels with Sharp and packed in
alphabetical filename order.
