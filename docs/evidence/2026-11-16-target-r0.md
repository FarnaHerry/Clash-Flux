每份冻结：生成 JSON 的原字符串（保留数值表现）、出站、错误、完整有序 fidelity/warnings、原规则及修改投影、来源对象目录、规则追溯 origins/count/labels 和参与来源。来源解析缓存命中计数受先前调用影响，不进入语义金样。

样例在转换器修改前冻结，另有独立手写契约核对成功/整份失败、目标中保留/消失的匹配、锚点冲突、降级记账和不可用全局目标保留匹配后拒绝。不是只比较两个新入口输出，测试也不提供写回预期的选项。

## R1 身份与兼容契约

第一批目标内容是实际生成的 sing-box 规则与默认动作，加最小目标出口目录；原生对象及数值完整保留。管理元信息单独持有，不注入内核 JSON。来源到目标映射须在实际发射处记录，包括未生成/终止原因；不能仅凭最终 JSON 或数组下标反推来源。

目标对象 ID 只在明确的产物版本内唯一，可由句柄/独立序号标识，不当成跨刷新身份。刷新重放使用来源格式、原规则锚点及转换分支映射，重复/多义拒绝自动匹配。现有运行追溯 ruleId 用于已应用计划关联，不直接提升为长期编辑 ID；来源名和最终 tag 也不是持久化规则身份。

| 旧操作/映射 | R1/R3 必须保留的行为 |
| --- | --- |
| prepend | 来源主规则之前、既有前置/全局/模式层之后；独立个人 ID；不能误变全局最高优先级 |
| before_final | 在主来源终止点之前；原生无条件规则视为 catch_all，不能只在数组末尾追加 |
| replace / disable | 必须唯一匹配现有可编辑来源锚点；禁用对象在工作模型保留，生成中排除；重复、消失、只读及冲突保持明确失败 |
| final | 修改来源默认动作；REJECT/DROP 可能降低为末尾规则＋DIRECT final，不能只改 route.final；禁止 main 自身回退 |
| 个人项 target 失效 | 保留条件，按 reject/direct/main 指定策略执行并记账，main 采用未经个人修改的来源默认出口 |
| 单来源规则 → 多目标规则 | 比如 resolve 前置与匹配本体，必须定义整体操作范围；不能只禁用其中一段导致语义改变 |
| 无输出、MATCH 后条目 | 目标对象表中不伪装成生效对象；诊断与必要来源映射保留。旧记录如何保留/报告无作用在 R3 定稿，不能静默删除旧修改 |
| 多来源/资源引用 | sourceId＋对象种类＋来源内原名保持隔离；资源 ID 不改绑最终 rule_set tag；次来源内部规则仍不进入主规则 |
| 多来源条目合成一个目标 | R1 若产生此情况须显式保留全部出处；第一批不新增合并/去重优化，不伪造唯一可编辑来源 |

R1 先增加内部目标结果和对应关系，保持现有编译/保存及 UI 入口；R2 才接入共享产物，R3 验证旧记录与目标编辑。原生 JSON 未知对象继续只读保留，内核不认识字段的配置仍可能被真实候选 check 拒绝，不能据此认为所有保留对象都可运行。

## 次数与内存测量

Linux Clang 21/libc++ Debug。每个独立进程构建 N 条 DOMAIN-SUFFIX 及 MATCH，先调用一次 InspectProfileRules(includeOriginal=false)，再调用两次 compileConfig；共 1,000/10,000/100,000 三组，各运行三轮。输出字节前后相同。原始 [CSV](2026-11-16-target-r0.csv)保留全部九轮。

| 规则数（不含 MATCH） | 查看投影 ms 中位数 | 首次编译 ms | 重复编译 ms | 进程峰值 RSS KiB 中位数 | 两次编译来源解析缓存命中 |
| --- | ---: | ---: | ---: | ---: | --- |
| 1,000 | 12.248 | 31.311 | 10.131 | 9,236 | 0 → 1 |
| 10,000 | 100.796 | 245.703 | 247.203 | 23,464 | 0 → 0 |
| 100,000 | 947.090 | 2,517.600 | 2,499.187 | 184,632 | 0 → 0 |

现有 loadCachedClashYaml 是 thread_local、最多 2 项、估算 4 MiB，单份原文超过 128 KiB 不保留；命中仍 YAML::Clone，继续转换规则。以上命中计数是生产编译器提供的实际计数；每轮公共 API 调用次数由消费程序控制（1 次投影、2 次编译），不是扫描器/底层所有解析调用的插桩次数。

查看路径仍完整扫描校验文档，普通规则走轻量投影，复杂 YAML 回落。小文件的重复编译收益来自现有源解析缓存，不是目标产物复用；大文件跨过门槛后仍承担重复来源解析和生成。10 万条最终 JSON 约 10.69 MB，生产缓存设计还须计入原文、DOM、管理信息、编辑快照及在用候选；不能直接套多个独立 32 MiB 预算。

峰值 RSS 是该独立消费进程保留第一次编译结果并进行第二次编译的高水位，不是新模型常驻大小、GUI 或 Android 真机内存；墙钟为合成 Debug 观察，无 CI 性能阈值。本轮未测真实 GUI 初次锁等待/挂载、进程重启持久化、Release 或设备耗时。
