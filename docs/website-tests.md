# 网站访问测试

桌面宽屏在日志之后、设置之前提供「网站测试」侧栏入口；桌面窄窗和 Android
在设置顶部「更多」进入。Compact 返回设置，二级页面覆盖底部导航。
入口复用 `website_test.svg`，卡片使用通用地球图标。

## 卡片与编辑

- 初始提供 Baidu、Bilibili、QQ、JD、Google、YouTube、GitHub、Cloudflare；它们与新增网站
  共用模型、编辑和删除操作，可全部删除后再添加。空列表保留添加入口，禁用全部测试。
- 宽屏为自适应网格，Compact 单列。卡片只显示名称，不显示地址副标题；宽屏移除三点按钮，
  右键卡片打开「编辑 / 删除」，Compact 保留三点按钮。删除须确认。
  右键菜单延迟显示任务由页面 TaskScope 持有，避免卡片重组中断菜单打开。
- 左下角：未测试、等待测试、测试中、已取消；成功且位置可确认时显示国旗与大写国家码
  （例如英国为 GB），位置无法确认时显示「位置未知」；HTTP 或传输失败统一红色「失败」，
  错误细节保留在提示中。国旗使用打包图集，不依赖操作系统的 emoji 字体。
- 右下角显示本次测试完成时间 `HH:mm:ss`，悬停可看完整日期时间；未完成过显示 `—`。
  不再显示 HTTP 状态码和耗时。排队/运行时清除旧结果，完成后记录本地时间。
- 单卡和页头「全部测试」使用刷新图标；排队/运行时禁用并复用 0.9 秒线性旋转，
  reduced motion 不旋转，完成/取消后复位。单卡忙碌不阻止其它空闲卡测试；
  任意卡忙碌时「全部测试」禁用。添加入口始终可用。
- 卡片保留主题底色与圆角，不描边。网格左右缩进与滚动正文首尾空白取
  `IslandTheme::nested_radius`，卡间距 8pt；ScrollArea 铺满正文。
  网格控制器随挂载，宽窄切换或卸载重挂恢复实际滚动偏移。
- 添加按钮位于页头；宽屏弹窗，Compact 独立表单页，共用草稿。
  字段顺序为「名称」「网站地址」，操作文案统一「编辑」。名称去首尾空白后使用；
  留空自动从域名或 IP 生成（去掉 `www.`、端口、路径与 IPv6 方括号），模型始终保存有效名称。
  表单使用统一 outlined TextField、16pt 字段间距、FormHeaderAction / FormPageContent，
  宽屏动作在弹窗底部。取消、Esc、遮罩、返回共用草稿放弃确认。
- URL 去首尾空白；裸域名（含端口/路径/查询）补 `https://`，`//` 补 `https:`。
  显式 HTTP/HTTPS 保留协议，协议和主机名小写、空路径补 `/` 后去重，保留路径/查询大小写。
  拒绝其它协议、用户信息、片段、空主机、无效端口、重复 URL 和规范化后超过 2048 字符的输入；
  最多 24 项。编辑自己的地址不算重复，满额仍可编辑/删除；失败 toast 并保留草稿和原站点。
  网站列表、草稿、结果只保留在当前 Runtime，不增加数据库键，也不迁移旧记录。

## 请求与位置来源

- 网站测试只使用应用共享的 HuxerUI HttpClient，遵循操作系统当前代理、路由、VPN/TUN
  及平台证书策略；不区分提供网络的是 Clash-Flux、Clash Verge、其它客户端或直连。
  不指定本地代理端口、节点或认证用户，不改系统网络设置，也不要求或启动本应用内核。
  原先强制经过自家待命内核的诊断入站、固定出站规则和控制器取证逻辑已移除。
- 仅显式单卡/全部测试发请求，最多 3 个并发。每个网站从实际执行开始共用 10 秒预算，
  包含 HEAD、重定向与位置请求；排队期间不计执行超时。网络请求使用剩余预算，模型另有
  独立的一次性 10 秒兜底：取消在途任务，记录「网站测试超时（10 秒）」及完成时间，
  结束忙态并释放槽位，继续后续队列。正常完成、取消、编辑或删除都取消对应兜底任务。
  旧请求/旧超时不能覆盖重试结果；切页、卡片卸载或宽窄切换不取消应用任务。
- 先对网站发 HTTP HEAD，沿平台正常重定向；2xx/3xx 为访问成功，4xx/5xx、DNS、TLS、
  连接和超时为失败。HEAD 被拒绝不改发 GET，成功不代表网页、脚本、登录或视频完整可用。
- 位置只查询最终目标网站**同源**的 `/cdn-cgi/trace`，仍使用系统当前网络；仅当目标网站
  支持该接口、HTTP 200、没有跨源重定向、正文不超过 4096 字节且含有效 IP/两字母 `loc`
  才显示国家码。Cloudflare 可提供此信息，GitHub/Google 等不提供时显示「位置未知」。
  不再用其它域名的位置服务或内部所选节点推断网站出口，因为外部客户端的规则可能不同。
  这是同源位置接口对该次请求的观测；轮换出口仍可能按连接分配不同公网 IP，不能证明两个
  请求的源 IP 完全相同。位置失败不改变已成功的 HTTP 访问结果。
- 默认平台证书和主机名校验始终开启；HEAD 不读取网页正文，位置 GET 采用流式读取，
  超出 4096 字节立即关闭。没有页面轮询、自动后台探测或额外阻塞工作线程。
  Android 测试反映应用自身实际网络（包括平台的应用级 VPN 排除），不替代其它应用、
  系统代理或完整 TUN 的数据面验收；iOS 仍暂缓。
- WebsiteTestModel 由应用服务持有；按稳定 ID 与请求代次发布，不按列表索引写回。
  请求按发起顺序排队，空槽继续；重复开始忽略。
  编辑地址先取消该站点并重置结果，仅改名称保留结果/在途请求；删除取消该站点，
  其它站点继续，重新添加相同地址获得新 ID。内部取消仍用于编辑、删除和任务清理。

## 验证

`page_transition` 挂载生产卡片与编辑表单，覆盖 320/960pt、宽屏右键/窄屏三点菜单、
名称回退（域名/IPv4/IPv6）、字段顺序、国旗/未知位置/失败/时间、地址校验与 24 项限额，
以及队列上限、请求卸载/取消、异常恢复、编辑删除、旧代次拒绝、滚动与宽窄重挂。
`ui_resources` 检查中英文资源和国旗图集/代码表与原始资产一致。

`page_transition` 还覆盖永久挂起请求的 10 秒硬超时、释放全部并发槽、排队继续、超时后
重试、旧定时器拒绝，以及网络适配器的 HEAD/同源位置请求顺序、共享剩余预算、跨源位置
拒绝、404/无效正文回退未知。Android Java/NDK 编译验证共享平台 HTTP 入口；不等于手机
VPN 或外部代理实机验收。实际命令与原生 GUI 范围见 [L1/L2/L3 状态](l1-l2-l3-status.md)。
