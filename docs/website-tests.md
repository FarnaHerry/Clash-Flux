# 网站访问测试

2026-11-05，v0.3.94 工作区新增。桌面宽屏在日志之后、设置之前提供「网站测试」侧栏入口；
桌面窄窗和 Android 在设置顶部「更多」直接进入。窄屏返回设置，二级页面覆盖底部导航。
入口共用独立的 `resources/images/website_test.svg`：浏览器窗口内的检测波形，24×24、
2pt 圆头描边，颜色跟随主题；网站卡片仍使用通用地球图标。

## 行为与范围

- 初始提供 Baidu、Bilibili、QQ、JD、Google、YouTube、GitHub、Cloudflare 八张卡片。
  这些站点只是初始列表，和新增站点共用模型、表单及操作菜单，均可编辑和删除；删除需确认，
  可全部删除再添加。宽屏使用自适应网格，Compact 为单列；卡片显示名称、完整 URL、状态、
  HTTP 状态码和耗时。空列表显示统一空状态，「全部测试」禁用，添加入口保留。
- 网格与首页的页面边缘留白共用卡片圆角 `IslandTheme::nested_radius`（当前 14pt），
  左右缩进与上下空白取同一值。上下以跨整行的空白项放在滚动内容内，并计入网格行距。
  页面骨架启用 `scrollToContentEdges`，滚动区域直达标题栏下沿与页面底部，空白随卡片滚走；
  卡片之间仍使用 8pt 间距。
  滚动控制器归网格的挂载生命周期，骨架切换后从保留的实际偏移恢复，避免宽窄切换跳回顶部。
- 手动「全部测试」或单卡「测试」才发请求；最多 3 个并发请求，每个 10 秒总超时。
  卡片之间互不影响：一张卡测试期间，其它卡仍可各自开始或取消自己的测试。
  HTTP HEAD 使用应用共享 HttpClient，沿用平台默认证书校验及重定向行为，不读取网页内容。
- 2xx/3xx 表示本次 HTTP 访问成功；4xx/5xx 显示「网站已响应」和原状态码；
  DNS、连接、TLS、超时等传输错误显示「连接失败」和平台错误。HEAD 被拒绝不改用 GET，
  有响应不代表页面、脚本、登录或视频能完整加载；耗时是请求总时长，不是节点延迟。
- 请求使用当前应用网络，不强制指定内核节点或出站。特别是 Android 为保留订阅下载通道，
  应用自身被排除在本应用 VPN 之外，因此结果不能验收其它应用的 VPN/TUN 分流；这一边界
  只在本说明记录，页面不再显示说明文字。
  系统网络、浏览器、其它应用或完整虚拟网卡数据面的验证仍需分别进行。
- 页头右上角「+」添加网站：宽屏弹出表单弹窗，Compact 进入独立二级页（返回箭头/系统返回
  回到列表），两处共用同一份草稿。批量和单卡测试使用 play 图标，测试中切换为 close
  取消图标，保留提示与无障碍名称；批量测试与「+」并排在页头动作区，
  页面不显示说明性文字。表单沿用应用统一的 MD3 平铺表单：`TextField` 加标签、outlined
  变体、16pt 行距；Compact 提交图标位于标题栏右侧，宽屏弹窗动作位于底部。
  字段为「网站地址」和「备注（可选）」：
  备注去首尾空白后成为卡片标题，留空则用网址主机名生成；URL 去首尾空白，裸域名
  （含端口/路径/查询）自动补 `https://`，`//` 开头补 `https:`；显式 HTTP/HTTPS 保留协议，
  协议和主机名统一小写、空路径补 `/` 后去重，不改路径/查询的大小写。拒绝非 HTTP(S)、
  用户信息、片段、空主机、无效端口、重复 URL 及规范化后超过 2048 字符的输入，总数最多
  24 项。添加/编辑失败用 toast 反馈并保留输入和原站点；取消、Esc、遮罩和返回共用草稿
  放弃确认。编辑自己的原地址不视为重复，满额时仍可编辑或删除。
  网站列表、输入和结果仅保留在当前应用 Runtime，不增加数据库键。
- WebsiteTestModel 由应用服务持有，应用任务域执行；切页、卸载卡片或宽窄切换不取消请求。
  每张卡独立排队与取消：单卡测试不阻塞其它卡、不要求其它卡空闲，也不取消其它在途请求；
  全局同时最多 3 个请求，超出上限的按发起顺序暂存，空出槽位后继续。
  单卡按钮在其测试期间变为「取消」，只结束该网站在途任务并标为已取消；页头「取消」
  结束全部在途与暂存任务。结果按稳定站点 ID 和请求代次核对后发布，
  删除/取消后的旧结果不会覆盖后续请求，也不受列表索引移动影响。修改地址先取消该站点
  的请求并重置结果，仅改备注保留结果和在途请求；删除取消该站点的排队/在途任务，
  其它站点继续执行。重新添加相同地址分配新 ID。添加入口不随测试进行而禁用。
  没有页面轮询和自动后台探测。

## 验证

`page_transition` 挂载生产卡片组件，使用应用任务域与可控异步探针验证 3 并发上限、
完整队列排空、重复开始被忽略、单卡在其它卡片运行时独立排队/取消、解除单个运行中
网站的槽位、离开发起页、全部取消、单卡重试；真实共享 HTTP 适配器在无窗口宿主
不支持网络时明确失败并结束忙态。320/960pt、视口切换、滚动空白和网格卸载重挂后
的实际偏移恢复、HTTP 403
与传输失败的不同呈现、自定义 URL 与备注校验（含留空回退主机名）和 24 项限额也在此
回归内。另覆盖地址自动补全与去重、默认站点编辑、失败保留草稿、Esc 草稿确认、
生产菜单删除确认、运行/排队期间编辑删除、ID 移位和删空后再添加。生产编辑弹窗与字段
由无窗口测试挂载；Compact 二级页面打开/返回、真实键盘及 Android 交互仍需实机核对。

`ui_resources` 核对中英文资源，Android 构建验证共享页面和后台平台入口能编译，
不替代 Android 真机流量。实际命令和本轮桌面 GUI 检查记录见
[L1/L2/L3 状态](l1-l2-l3-status.md)。
