# Clash-Flux v0.3.99

## 简体中文

- 页面滚动留白统一：装饰性首尾空白归滚动正文，滚动视口直达固定标题下沿和页面底边；虚拟列表/网格使用不可交互的首尾空白项，业务索引与稳定 ID 保持不变。新增 `page_layout.h` 共享留白组件，首页、订阅、代理、规则、连接、日志、设置、网站测试、外部资源、保真度及二级页统一读取 `IslandTheme::nested_radius` / `dense_radius`；悬浮导航与测速按钮的尾部避让单独叠加；可滚动列表/网格的加载骨架与真实内容使用同一首尾规则。
- 窄屏编辑/添加页主操作移到标题栏右侧的 `FormHeaderAction`：订阅添加/编辑/文本、个人与全局规则、规则集、网站测试、颜色及网络编辑不再固定底部提交按钮；正文用 `FormPageContent` 只避让底部系统安全区，键盘缩短视口时图标保持在顶部。网络表单的保存图标在有「保存并应用」时弹出两项动作菜单，提交忙态使用同尺寸进度指示。
- 二维码/配置导入：二维码与文件入口各自持有忙态，同一入口拒绝重复提交，另一入口不会被误标为加载中；URL/PPTP 创建表单的忙态归当前实例。已提交的导入归应用任务域，慢下载期间仍可返回/关闭，只有未提交草稿变化需要确认；返回、卸载或发起新操作后，旧结果不再触发页面跳转，但仍发布已提交数据并反馈。提交前快照全部输入，重新打开的表单不会被旧结果关闭。
- 自家 QRS 分享集齐帧后按完整配置字节本地导入，不再把单帧 Base64 当作订阅链接下载；新增 YAML/JSON、压缩/未压缩 QRS 的逐字节还原回归，未集齐帧不提交。
- 网站测试：批量与单卡测试改为 play/close 图标动作，运行中显示取消，保留提示与无障碍名称；网格在宽窄切换或卸载重挂后恢复实际滚动偏移，并统一首尾留白。
- 代理页整体测速仍由内核 `/group/{name}/delay` 批量执行，保留组 URL、内核并发和历史写入顺序；UI 在批处理期间读取 `/proxies` 快照，每个节点在结果写入内核 history 后立即显示自己的延迟，不再等整组结束。
- Linux aarch64 不再作为可失败实验项：标签 CI 必须通过 arm64 构建与门禁，`publish-release` 显式要求 x86_64/aarch64 的 tar.gz、deb、rpm 全部存在，避免缺少架构仍创建不完整 Release。
- 桌面 CLI 命令改为在无窗口启动任务中执行，不再创建隐藏 GUI 窗口；命令落库后直接退出，避免运行时停止期间组合/卸载页面造成的竞态，也让数据库与规则集命令更快结束。
- Android versionName 为 **0.3.99**，versionCode 为 **177**（上一发布 176）。HuxerUI 更新到 `69f24079`，修复单行输入框尾部光标在横向滚动后不可见；sing-box/libbox 1.14.4 及其它依赖固定版本不变。
- 验证：桌面全目标构建、**31/31** 必跑回归通过（含 page_transition / qrs_codec / persistence）；Android Debug Java/NDK/APK 构建通过，并以 aapt 核验 APK 的 versionName/versionCode。此前工作区已完成 Linux X11 首页、网站测试、窄屏导入表单的实窗检查；本轮未做其它平台真机、真实 VPN 或正式签名安装验收，发布产物与 APK 签名由标签 CI 核验。

## English

- Unified page scroll spacing: decorative leading/trailing gaps now belong to the scrolling body, and the viewport reaches the fixed header's bottom edge and the page bottom. Virtual lists/grids use non-interactive edge items while preserving business indexes and stable IDs. New shared helpers in `page_layout.h` make the home, subscriptions, proxies, rules, connections, logs, settings, website tests, external resources, fidelity and secondary pages read `IslandTheme::nested_radius` / `dense_radius` consistently. Floating navigation and speed-button avoidance is added once at the tail, and loading skeletons for scrollable lists/grids follow the same edge rule as real content.
- Compact edit/add forms move their primary action to a header-right `FormHeaderAction`: subscription add/edit/text, personal and global rules, rule sets, website tests, colors and network editing no longer keep a fixed bottom submit button. `FormPageContent` only avoids the bottom system safe area, and the icon stays in the header when the keyboard shortens the viewport. The network form's save icon opens a two-item menu when “Save and apply” is available, with a same-size progress indicator while busy.
- QR/config import: QR and file entries keep independent busy states; the same entry rejects duplicate submits while the other entry is not falsely marked as loading. URL/PPTP create-form busy state belongs to the current instance. Submitted imports belong to the application task scope, so a slow download can be left or closed; only unsaved draft changes require confirmation. After back, unmount or a newer action, stale results no longer navigate the page but still publish committed data and feedback. All inputs are snapshotted before submit, and a reopened form cannot be closed by an old result.
- The app's own QRS share now restores the full configuration bytes after all frames are collected and imports it locally, instead of treating a single Base64 frame as a subscription URL. Added byte-for-byte YAML/JSON, compressed and uncompressed QRS regressions; incomplete frame sets are not submitted.
- Website tests: bulk and per-card testing use play/close icon actions, showing cancel while running with tooltips and accessibility labels. The grid restores its real scroll offset after wide/compact switches or remounts and shares the same edge spacing.
- Proxy bulk testing still runs through the kernel `/group/{name}/delay` batch, preserving the group URL, kernel concurrency and history write order. While the batch runs, the UI reads `/proxies` snapshots so each node publishes its own delay as soon as the kernel writes its history, instead of waiting for the whole group to finish.
- Linux aarch64 is no longer an allowed-to-fail experiment: tag CI must pass the arm64 build and gate, and `publish-release` explicitly requires the x86_64/aarch64 tar.gz, deb and rpm assets so an incomplete Release cannot be created when one architecture is missing.
- Desktop CLI commands now run in the windowless startup task instead of creating a hidden GUI window. They exit right after flushing, avoiding composition/teardown races during runtime shutdown and making database and rule-set commands finish faster.
- Android versionName is **0.3.99**, with versionCode **177** (previous release 176). HuxerUI is updated to `69f24079`, fixing the trailing caret becoming invisible after horizontal scrolling in single-line text fields; sing-box/libbox 1.14.4 and other dependency pins are unchanged.
- Verification: the full desktop build and **31/31** required regressions passed (including page_transition / qrs_codec / persistence). Android Debug Java/NDK/APK builds passed, with the APK versionName/versionCode checked via aapt. Earlier workspace checks covered Linux X11 home, website tests and the compact import form in a real window. Other platforms' devices, real VPN and signed installation were not verified in this round; tag CI verifies release artifacts and the APK signature.
