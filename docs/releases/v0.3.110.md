## 中文

- 统一桌面首窗和托盘启动。应用启动或设置中安装服务成功后进入待命，停核后单击测速会拉起待命内核并执行原请求。
- 托盘新增「出站模式」子菜单，可切换规则、全局和直连。
- 首页系统代理和虚拟网卡的齿轮与标题图标对齐，随机彩蛋新增五个官方 HuxerUI 扩展库链接。
- HuxerUI 更新至 `11849f99`，合入上游 Windows 彩色 emoji、全屏 topmost 修复，并修复受控 Pager 在拖动中禁用时回弹到离场页的问题。
- Android versionName 为 `0.3.110`、versionCode 为 `188`；iOS 仍暂缓且不提供发布资产。

## English

- Unify desktop window and tray startup. The core enters standby after startup or service installation. A delay test can start a stopped core in standby and continue the original request.
- Switch between Rule, Global, and Direct from the tray's Outbound mode submenu.
- Align the home dashboard settings gears with their card icons and add five official HuxerUI extension links to the Easter egg pool.
- Update HuxerUI to `11849f99` with upstream Windows color emoji and fullscreen topmost fixes, plus controlled Pager settling on the selected page when dragging is disabled mid-gesture.
- Android versionName is `0.3.110` and versionCode is `188`; iOS remains deferred with no release asset.
