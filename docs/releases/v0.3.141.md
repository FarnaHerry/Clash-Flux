## English

- Added a signed GitHub Pages APT / RPM Linux package repository (`https://farnaherry.github.io/Clash-Flux/`): `publish-release` runs `scripts/build-linux-repo.sh` with a dedicated RSA-4096 GPG signing key (`5D58F92EC9A683FE42638DBF89A86E971F6EFD47`) to sign `.rpm` packages and generate signed `InRelease`/`Release.gpg`/`repomd.xml.asc` metadata before `deploy-linux-repo` deploys via `actions/deploy-pages`.
- Updated `install.sh` on Linux to verify the pinned GPG public key fingerprint and SHA-256, configure the signed APT (`Signed-By`) or RPM (`gpgcheck=1`, `repo_gpgcheck=1`) repository, and install into `/opt/clash-flux` so subsequent `apt upgrade`/`dnf upgrade` updates seamlessly trigger silent root `systemd` service self-upgrade; added a post-install check warning about leftover user-local `PATH` shadowing (such as `~/.local/bin/clash-flux`); kept `.tar.gz` and Windows `.zip` in GitHub Releases as fallback archives and kept macOS `.dmg` installation unchanged.
- Updated `install_scripts` tests and README / app-update documentation.
- Android versionName is 0.3.141 and versionCode is 218.
