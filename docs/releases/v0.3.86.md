# Clash-Flux v0.3.86

## 简体中文

- 桌面组测速改为统一调用 sing-box 的 `/group/{name}/delay`，由内核按原生并发 10 批量测试；不再由 UI 逐节点 fan-out。
- URLTest 组继续保留订阅的 `url-test.url`、`interval` 和 `tolerance`；普通组使用内核默认测速地址。
- 单节点测速改为传空 URL，使用 sing-box 自身默认 HTTPS 地址；超时统一为 15 秒，对齐 `constant.TCPTimeout`。
- 删除桌面 8 并发逐节点测速路径，减少错误测速地址、组参数丢失和并发排队造成的延迟偏差。
- Android 组测速保持 `CommandClient.urlTest(group)`，与 SFA 行为一致。
- Android versionCode 为 164；桌面与 Android 之外的行为不变。

## English

- Desktop group tests now always call sing-box `/group/{name}/delay`, letting the kernel run its native batch with concurrency 10 instead of fanning out per node from the UI.
- URLTest groups keep the subscription's `url-test.url`, `interval` and `tolerance`; other groups use the kernel default test address.
- Single-node tests now pass an empty URL and use sing-box's default HTTPS address; the timeout is aligned to `constant.TCPTimeout` at 15 seconds.
- Removed the desktop 8-way per-node probe path, avoiding wrong test URLs, lost group parameters, and queueing-related latency skew.
- Android group tests remain `CommandClient.urlTest(group)`, matching SFA behavior.
- Android versionCode is 164; behavior outside desktop and Android is unchanged.
