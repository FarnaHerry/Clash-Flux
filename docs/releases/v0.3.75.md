# Clash-Flux v0.3.75

## 简体中文

- 内置内核升级 sing-box 1.14.4（桌面六平台资产、Android libbox、iOS 源码 pin 同步对齐）：转换订阅时自动去重策略组重复成员并保真度记账（1.14.4 拒绝重复成员）；Android 10 以下改用 1.14.4 新的 `Libbox.findConnectionOwner` 接口做连接归属查询。
- 设置页末尾改为「关于」入口，新增独立关于页：Logo、版本、简介、仓库链接、免责声明，以及只读检查 GitHub 最新稳定 Release 的更新检查（检查期间图标旋转，尊重减少动画设置）。
- 设置页布局统一：分组标题移到卡片外并按内容对齐，组面板零内边距由整组圆角裁切，主题/语言/端口/运行诊断等入口共用全宽行。
- 交互反馈统一：hover/focus/press/ripple 透明度收敛为主题常量，首页出站模式改用框架 RadioButton；语言入口跨平台响应式（窄屏进页面、宽屏弹窗）。
- 浅色主题中性表面由暖白微调为冷白并统一全部浅色角色；桌面轻量托盘窗口改为正常关闭，关闭最后一个窗口不再退出应用（退出走托盘 Quit）。
- Toast 统一下移 8pt、98% 缩放与 200ms 淡出（减少动画时禁用位移/缩放）；修复二级页直接切回首页时的共享键冲突崩溃。

## English

- Upgrade the bundled core to sing-box 1.14.4 across all six desktop assets, the Android libbox and the iOS source pin: duplicate proxy-group members are now deduplicated during subscription conversion with a fidelity note (1.14.4 rejects duplicate members), and Android below API 29 uses the new `Libbox.findConnectionOwner` API for connection-owner lookup.
- Replace the settings footer with an About entry and add a dedicated About page: logo, version, description, repository link, disclaimer, and a read-only check for the latest stable GitHub Release (spinning icon while checking, respects reduced motion).
- Unify the settings layout: group headings move outside cards aligned with content, group surfaces use zero padding with whole-group corner clipping, and entries such as theme, language, ports and runtime diagnostics share full-width rows.
- Unify interaction feedback: hover/focus/press/ripple opacities come from theme constants, the home outbound-mode selector uses the framework RadioButton, and the language entry is responsive (page on narrow screens, dialog on wide).
- Tune the light theme neutral surfaces from warm white to cool white across all light roles; on desktop the lightweight tray window now closes normally, and closing the last window no longer quits the app (quit via the tray menu).
- Toast notifications move down 8pt, scale to 98% and fade out over 200ms (disabled under reduced motion); fix a shared-key conflict crash when switching directly from a secondary page back to home.
