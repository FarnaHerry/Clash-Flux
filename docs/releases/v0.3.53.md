# Clash-Flux v0.3.53

## 简体中文

- Windows 代理节点列表现在能显示 UTF-8 国旗 Emoji 对应的国旗图案，节点原始名称、搜索和无障碍文本保持不变。
- 优化 MRSv1 域名规则生成：同域名的精确匹配与子域匹配合并为原生后缀规则，减少规则数量；单独的子域规则仍不匹配根域名。
- 优化订阅配置生成，复用已解析的候选 JSON，减少重复解析和序列化。

## English

- Windows proxy node lists now render country flags for UTF-8 flag emoji while preserving the original node names, search text, and accessibility text.
- MRSv1 rule generation now combines exact-domain and subdomain matches for the same domain into one native suffix rule, reducing rule count; standalone subdomain rules still exclude the root domain.
- Subscription configuration generation reuses the parsed candidate JSON to avoid redundant parsing and serialization.
