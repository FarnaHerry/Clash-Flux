# Clash-Flux v0.3.81

## 简体中文

- 修复桌面待命内核在 Clash Verge 等客户端开启全局 TUN 时误报网络接管冲突的问题。待命不开放业务入站，可与已有全局 TUN 共存。
- 显式连接代理时仍检查其他客户端的全局接管；候选 TUN 的接口名和地址冲突检查继续生效。
- Android VPN 生命周期没有变化。

## English

- Fix desktop standby startup being rejected when another client, such as Clash Verge, owns a global TUN. Standby opens no traffic inbounds and can coexist with an existing global TUN.
- Connecting still checks other clients' global traffic takeover. Candidate TUN interface-name and address conflicts remain guarded.
- The Android VPN lifecycle is unchanged.
