# Clash-Flux v0.3.62

## 简体中文

- 改善运行诊断弹窗在深色主题、窄窗口和长报告下的可读性；复制报告会提示操作结果。
- 加粗选中卡片的边框，并提升深色模式中禁用按钮文字的可读性。
- 加强 Windows 与 Linux PPTP 连接失败、断开确认和路由租约清理，避免失败操作误撤出现有连接或主路由。

## English

- Improved runtime diagnostics readability in dark themes, narrow windows, and long reports; copying a report now shows its result.
- Made selected-card outlines clearer and improved disabled-button text in dark mode.
- Hardened Windows and Linux PPTP failure handling, disconnect confirmation, and route-lease cleanup to protect existing connections and routes.
