## 中文

- 优化右键及操作菜单图标悬停动效与弹层视觉区分度：在 `ActionMenuItemView` 中为图标悬停加入两段式轻跳动画（首跳 `1.0 -> 1.12 -> 1.0`，次跳减弱为 `1.0 -> 1.06 -> 1.0`）；通过 `FluxMenuSurfaceColor` 为菜单设置高于普通卡片且无外描边的浮层底色（深色 `surface_container_high`、浅色纯白），并将 `ResolveFluxShadows::popup` 调整为四向均匀柔和投影（深色 0.44 / 浅色 0.22，偏移 `(0, 0)`，模糊 `18pt`），避免底部拖影过重并提升与下层卡片的层级辨识度。
- 补齐代理页加载骨架在不同视图模式与视口断点下的自适应切换：`ProxyLoadingSkeleton` 统一用于桌面端与移动端，随 `SettingsModel::proxyGroupedView`（设置未就绪时默认按分组视图）切换为纵向折叠组卡列表（6 个 `67pt` 高 `14pt` 圆角占位卡片及 `14pt` 间距）或顶部分组标签条加节点网格（Compact 固定 2 列，桌面宽屏按 `kProxyNodeWidth` 自适应列数，节点卡 `56pt` 高 `8pt` 圆角）；同步更新 `test_page_transition` 回归与 UI 开发文档。
- Android versionName 为 0.3.138，versionCode 为 215。

## English

- Refined right-click and action menu hover feedback and popup separation: updated `ActionMenuItemView` with a two-step icon bounce on hover (primary `1.0 -> 1.12 -> 1.0` followed by a smaller secondary `1.0 -> 1.06 -> 1.0` bounce), elevated borderless menu surface colors via `FluxMenuSurfaceColor` (`surface_container_high` in dark mode, pure white in light mode), and switched `ResolveFluxShadows::popup` to an even omnidirectional shadow (dark opacity `0.44` / light opacity `0.22`, offset `(0, 0)`, blur `18pt`) to eliminate heavy bottom-edge overhang while keeping menus clearly separated from underlying cards.
- Unified and completed view-aware `ProxyLoadingSkeleton` across desktop and mobile/Compact viewports: `ProxiesPage` now switches loading placeholders according to `SettingsModel::proxyGroupedView` (defaulting to grouped while settings hydrate), rendering collapsed group card placeholders (`67pt` tall, `14pt` corners and gaps) in grouped mode or a tab bar above a `56pt`-tall `8pt`-radius node grid (`2` columns in Compact, adaptive `kProxyNodeWidth` columns on wide desktop) in tabbed mode, with updated `test_page_transition` coverage and UI documentation.
- Android versionName is 0.3.138 and versionCode is 215.
