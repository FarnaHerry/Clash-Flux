# Clash-Flux v0.3.17

## 简体中文

- 支持通过 sing-box、FlClash 和 Clash 网页链接打开订阅导入表单；粘贴和扫码入口也能解析这些链接。检查信息并确认后才会导入。
- 修复 Clash 节点凭据空白被裁掉的问题，并保留 OpenVPN inline 凭据原文；异常 TLS、ALPN 和传输字段会明确拒绝并显示保真度原因。
- 支持按来源继承全局 TLS 指纹，节点级设置优先；多个订阅来源之间相互隔离。

## English

- Open subscription import from sing-box, FlClash and Clash web links. Pasting and QR import also parse these links; review the details and confirm before importing.
- Preserve whitespace in Clash node credentials and literal OpenVPN inline credentials. Invalid TLS, ALPN and transport values are rejected with a fidelity diagnostic.
- Inherit the global TLS fingerprint within each source, allow a node setting to override it, and keep subscription sources isolated.
