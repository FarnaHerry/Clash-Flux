# Clash-Flux v0.3.38

## 简体中文

- Windows 安装器同版本检测修复：重新打开同一版本的安装器此前会误报「已安装新版本」（升级拦截页），真正的旧版本升级反而从未被识别、直接当作全新安装；现在按版本序比较——同一版本进入维护页（可重装/卸载），更新版本仍然拦截降级，旧版本注册正常升级。
- HuxerUI 框架固定版本升级到 `42f0069`：安装器检测与命令策略修正之外，iOS 链接解析重构为独立的 `HuxerUIIosLink.cmake`（生成器表达式先求值再解析目标依赖，保留库参数与传递链接选项，附专项测试）。

## English

- Windows installer same-version detection fixed: reopening the installer for the version already installed previously misreported "a newer version is installed" (the downgrade-block page), while a genuine older-version upgrade was never detected at all and rendered as a fresh install. Detection now compares versions: the same version lands on the maintenance page (repair/uninstall), a newer registration still blocks downgrades, and an older registration upgrades normally.
- The pinned HuxerUI framework is updated to `42f0069`: beyond the installer detection and command-policy fixes, the iOS link resolution is reworked into a dedicated `HuxerUIIosLink.cmake` (generator expressions are evaluated before resolving target dependencies, preserving library arguments and transitive link options, with dedicated tests).
