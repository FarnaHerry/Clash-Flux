# Clash-Flux v0.3.25

## 简体中文

- 设置页统一使用图标入口，主题支持 HSB 调色、颜色编辑与管理；端口设置改为弹窗，可分别配置混合、HTTP 和 SOCKS 入站。
- 首帧集中读取主题、语言与托盘设置，避免启动时短暂显示错误外观或托盘状态；托盘菜单语言与应用保持一致。
- Android 页面背景延伸到顶部系统栏，安全区颜色随主题统一。
- 修正 Android 活动连接目标地址重复显示端口的问题。
- 分享二维码弹窗与订阅卡片菜单得到简化，并新增复制订阅链接操作。

## English

- Settings now uses consistent icon entries, an HSB theme color editor, and a dialog for separate mixed, HTTP, and SOCKS inbound ports.
- Theme, language, and tray preferences load together before the first frame, preventing a brief incorrect appearance or tray state. Tray menu language follows the app.
- Android page backgrounds now extend through the top system bar, with the safe area matching the active theme.
- Android active connection destinations no longer display the port twice.
- The QR sharing dialog and subscription card menu are simpler, and the menu can copy a subscription link.
