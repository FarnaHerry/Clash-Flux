## English

- Pin the HuxerUI source to `eb190f3d`: `farna/main` merged the official 0.4.0 release baseline (`85d65da5`) and the source CLI adds installed-SDK version management (`2f079bae`).
- Upgrade the offline SDK archive from 0.3.0 to official 0.4.0: Lock.cmake and CI verify the same SHA256 (`86837f3e…`); the Android job now uses the 0.4.0 CLI from the archive and builds the same-source Java/native framework with `--sdk huxerui-source`. The 0.3.0 archive is removed from the repository.
- Add a configure-time guard for the fork-only `create_initial_window` API: the official archive lacks it, so misusing the official package for desktop targets fails explicitly instead of linking silently.
- Sync the pinned-version and fallback-archive documentation (third_party/README.md, docs/huxerui-fork.md, docs/android-build.md, both READMEs) and fix the stale sing-box version description in the READMEs (actually pinned to 1.14.4).
- Verification boundary: this round verified the archive SHA256, local checkout vs CI pin consistency, and `git diff --check`; the main target build and required regressions were not re-run per user instruction.
