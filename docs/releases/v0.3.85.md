# Clash-Flux v0.3.85

## 简体中文

- 修正测速语义：Android 组测速改为调用该组自身的 URLTest，使用订阅配置的 `url-test.url`、`interval` 和 `tolerance`，不再把 URLTest 组降级为 selector 后逐节点使用内核默认地址。
- 桌面单节点延迟测试改用 HTTPS 测速地址，并把超时从 3 秒提高到 10 秒。sing-box 的 Clash API 会丢弃 HTTP 测速地址，旧地址实际没有生效。
- 组测速保留订阅的测速地址，避免测速结果与参数和实际 `url-test` 行为不一致。
- Android versionCode 为 163；其余平台行为不变。

## English

- Fix latency-test semantics: Android group tests now call the group's own URLTest and use the subscription's `url-test.url`, `interval` and `tolerance` instead of lowering the group to a selector and testing members with the core default URL.
- Desktop single-node delay tests now use an HTTPS test URL and a 10-second timeout. sing-box's Clash API discards HTTP test URLs, so the previous address was not actually used.
- Group tests retain the subscription test URL, keeping results and parameters consistent with the real `url-test` behavior.
- Android versionCode is 163; other platforms are unchanged.
