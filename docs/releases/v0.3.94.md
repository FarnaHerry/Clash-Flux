# Clash-Flux v0.3.94

## 简体中文

- 系统代理和虚拟网卡新增高级设置：本地监听端口/地址、绑定接口、认证和客户端网段；虚拟网卡 stack、DNS 接管、网卡名称/地址、接管与排除网段、UDP 会话参数及 Android 应用范围。支持的选项按平台展示，取消保留原配置，保存前统一校验完整候选。
- Linux 新增自动重定向及接口、UID 范围、MAC 筛选。Linux/Windows 可使用全局规则集中的目标 IP CIDR 设置虚拟网卡接管或排除范围，受引用的资源不能被删除；空集合或缺少某一地址族不会扩大为全流量接管。
- 系统代理支持本机 PAC 和自定义 HTTP(S) PAC URL。使用实际已接受的 HTTP/混合监听，保留原系统代理快照；释放时检查所有权，避免覆盖其他客户端的修改。本机 PAC 服务仅限回环监听，不添加代理失败后的自动直连兜底。
- 重排设置页与网络编辑器：系统代理分为系统接管、本地监听、访问控制；虚拟网卡分为基础、接管范围、UDP。宽屏弹窗和窄屏页面共用草稿，标签切换及宽窄切换保留编辑状态和滚动；窄屏「更多」可直接进入规则、连接、日志。
- 统一弹窗与表单为单层主题表面，内部字段平铺；固定标题和底部操作，正文可滚动。移除弹窗右上角关闭叉号，取消/关闭按钮统一采用 outline 描边，保留悬停、按压、键盘焦点与禁用反馈；长条设置行反馈覆盖完整单元格。
- 订阅、规则与网络编辑复用草稿关闭检查。异步保存等待结果，失败保留输入，成功先发布共享状态再关闭，避免页面之间显示不同步。
- 修复启动时 API 客户端刷新凭据与后台请求并发导致的崩溃。客户端保持存活，通过加锁更新端点；新增真实 HTTP 请求跨数据库加载、凭据刷新及数据重开的必跑回归。
- 本地完整桌面构建及 30/30 必跑回归通过，覆盖真实内核、资源管理、TLS 拒绝、持久化与 UI；独占网络命名空间的路由/nftables/退出清理检查通过。Android Debug Java/NDK 与五项策略回归通过。正式多平台安装包与 APK 签名由标签 CI 核验。
- 边界：独立资源更新仍要求应用 Runtime 存活；部分资源变更需候选重启。完整 Clash 兼容、JSON 次来源、连接到具体 L3 规则的追溯和跨重开崩溃事务继续按后续计划推进。Android 真机 VPN、正式签名覆盖安装与 Windows/macOS 系统接管及安装升级/回滚/卸载不因编译或 CI 通过而视为实机验收。
- Android versionCode 为 172；sing-box/libbox 保持 1.14.4。

## English

- Added advanced System Proxy and Virtual Adapter settings: local listener ports/addresses, bind interface, authentication and client CIDRs; adapter stack, DNS interception, interface name/addresses, included/excluded routes, UDP session controls and Android application scope. Options follow platform capabilities, cancellation preserves the existing configuration, and saving validates the complete candidate.
- Added Linux automatic redirection and interface, UID-range and MAC filters. Linux/Windows can select destination IP CIDRs from global rule sets for adapter inclusion or exclusion, with referenced-resource deletion protection. Empty sets or a missing address family do not expand into full-traffic capture.
- System Proxy now supports a local PAC service and custom HTTP(S) PAC URLs. It uses accepted HTTP/mixed listeners and preserves the original system-proxy snapshot; release checks ownership before restoring it. The local PAC listener is loopback-only and does not add a direct fallback when the proxy fails.
- Reorganized Settings and network editors into related tabs. System Proxy groups system integration, local listeners and access control; Virtual Adapter groups basics, capture scope and UDP. Wide dialogs and narrow pages share drafts and preserve tab/viewport editing state and scrolling. Narrow More navigation exposes Rules, Connections and Logs directly.
- Unified dialogs and forms around one themed surface with flat fields, fixed headers/actions and scrollable bodies. Removed title-bar close icons; Cancel/Close uses an outlined style with hover, press, keyboard-focus and disabled feedback. Settings-row feedback covers the entire allocated cell.
- Subscription, rule and network editors share unsaved-draft protection. Asynchronous saves retain input on failure and publish shared state before closing on success.
- Fixed a startup crash caused by replacing the API client while background requests were using it. Credential changes now update the retained client under its endpoint lock. A required regression holds a real HTTP request across database hydration and verifies credential refresh and data reopening.
- Local full desktop builds and all 30 required regressions passed, covering the real core, resource management, TLS rejection, persistence and UI. Disposable-network route/nftables/cleanup checks also passed, along with Android Debug Java/NDK and five policy regressions. Tag CI verifies the release packages and APK signature.
- Boundaries: independent resource scheduling still requires a live application Runtime, and some resource changes require candidate restart. Complete Clash compatibility, JSON secondary sources, precise L3 rule attribution and crash transactions across reopening remain future work. Builds and CI do not constitute Android device VPN/signed-upgrade acceptance or Windows/macOS system-integration and installer upgrade/rollback/uninstall acceptance.
- Android versionCode is 172; sing-box/libbox remains 1.14.4.
