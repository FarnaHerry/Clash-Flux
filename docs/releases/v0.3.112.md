## English

- Fix connection compatibility for legacy VMess TLS links with an omitted cipher or `auto`.
- Vertically center latency on the right of proxy cards. The number omits `ms` and shares its position with the per-node latency test button.
- Reuse the converted source across the rules list, editor, and configuration preview while preserving saved personal rule edits.
- Load large rule subscriptions on demand to avoid rebuilding snapshots evicted shortly after startup.
- Android versionName is 0.3.112 and versionCode is 190. iOS remains deferred without release assets.
