## 中文

- 修复代理页分组视图中冻结组头在滚动时顶部圆角看似丢失的问题：新增 `PinnedProxyGroupCornerMask`，在组头冻结时于圆角面板下方绘制与页面底色（`IslandTheme::base`）一致的顶部圆角遮罩，避免下方滚动的节点行与卡片从组头顶部圆角外侧透出；同步补充 `test_page_transition` 渲染快照回归与开发文档说明。
- Android versionName 为 0.3.137，versionCode 为 214。

## English

- Fixed frozen proxy group headers appearing square-cornered while scrolling in the grouped Proxies view: added `PinnedProxyGroupCornerMask` to paint `IslandTheme::base` top corner masks behind the pinned header's rounded panel so scrolling node rows and cards underneath no longer bleed through the top rounded corners, with render-snapshot regression tests in `test_page_transition` and updated UI documentation.
- Android versionName is 0.3.137 and versionCode is 214.
