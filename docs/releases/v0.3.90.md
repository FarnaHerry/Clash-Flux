# Clash-Flux v0.3.90

## 简体中文

- 修复 Android 订阅在切换下载身份后，可能把仅含远程代理提供者的配置静默编译成 `Proxy → DIRECT` 并通过候选检查的问题。
- 普通订阅恢复 v0.3.82 的 `clash-flux/0.1` 默认 User-Agent；仅收到 HTTP 403 时使用 `clash.meta` 重试。自定义请求头和规则集下载不走该重试。
- 尚未支持展开的 `use` / `include-all-providers` 代理组现在明确拒绝候选，不再只保留部分成员或退回 DIRECT。刷新失败保留旧订阅文件、选中状态及其他订阅。
- 本版本尚未完整支持 `proxy-providers` 下载和节点展开。未做 Android 真机外网及正式签名覆盖安装验收。
- Android versionCode 为 168。

## English

- Fixed an Android subscription path where changing the download identity could allow a provider-only configuration to compile silently as `Proxy → DIRECT` and pass candidate validation.
- Ordinary subscriptions again use the v0.3.82 `clash-flux/0.1` User-Agent by default, retrying with `clash.meta` only after HTTP 403. Custom request headers and rule-set downloads do not use this fallback.
- Groups requiring unsupported `use` / `include-all-providers` expansion now reject the candidate instead of keeping only partial members or falling back to DIRECT. A failed refresh preserves the previous subscription file, selection and all other sources.
- Full `proxy-providers` downloading and node expansion are not implemented in this release. Android device Internet access and signed upgrade installation have not been verified on-device.
- Android versionCode is 168.
