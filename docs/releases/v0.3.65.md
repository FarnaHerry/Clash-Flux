# Clash-Flux v0.3.65

## 简体中文

- 移动端与桌面 Compact 首页新增固定 48pt 标题槽位：未运行时显示“首页”和右下角猫咪；真实内核（桌面）/VPN（移动端）成功出箱后，猫咪按桌面同款轨迹飞入标题中心并展开为“运行中 + HH:MM:SS”，点击运行栏可直接停止。
- Android 首页运行时长改为由后台 `VpnUptime` 计时：只在 VPN 真正连接成功后以单调时钟记录会话起点，状态与已运行毫秒数随 Binder 快照成对发布，锁屏休眠、切页和 UI 重建不重置计时；core-only 不再开始计时。
- 运行文案统一为“运行中 / 正在启动 / 正在停止”，操作标签保留“启动/停止内核”“启动/停止 VPN”。
- 新增回归：`test_page_transition` 挂载生产标题/悬浮组件验证替换动画，`VpnUptimeTest` 验证后台会话计时契约。

## English

- Mobile and desktop Compact home now have a fixed 48pt header slot: it shows "Home" with the cat at rest, and after a real core (desktop) / VPN (mobile) successful unbox the cat flies to the header center and expands into "Running + HH:MM:SS"; tapping the running bar stops it directly.
- Android home uptime is now tracked by the background `VpnUptime`: it starts a session only after the VPN is actually connected, using a monotonic clock, and publishes state plus elapsed milliseconds in the same Binder snapshot — screen lock, page switches and UI rebuilds no longer reset the timer, and core-only no longer starts a session.
- Running copy is unified to "Running / Starting / Stopping"; action labels keep "Start/Stop core" and "Start/Stop VPN".
- New regressions: `test_page_transition` mounts the production header/fab components to verify the replacement animation, and `VpnUptimeTest` verifies the background session-clock contract.
