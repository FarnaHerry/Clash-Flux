# Clash-Flux v0.3.42

## 简体中文

- Linux 和 Windows 首页点击 TUN 时，如果尚未安装系统服务，会直接进入与设置页相同的服务安装授权流程。
- 修复多平台内核停止流程：等待 sing-box/libbox 确认退出；超时或关闭失败时显示失败状态，不再误报已停止。
- 修复持续输出时桌面内核强制停止计时无法触发，以及 Windows 服务未确认内核退出就回复成功的问题。

## English

- On Linux and Windows, selecting TUN on Home now opens the same elevated service installation flow used in Settings when the service is missing.
- Core shutdown now waits for sing-box/libbox to confirm exit across platforms. Timeouts and close failures remain visible instead of reporting a false stop.
- Fixed desktop force-stop timing when the core keeps writing output, and Windows service replies that reported success before confirming process exit.
