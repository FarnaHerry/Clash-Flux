# Clash-Flux v0.3.63

## 简体中文

- 首页新增展示真实 VPN 运行状态的猫咪动画卡片，并优化移动端和桌面窄窗口的首页空间。
- 增加跨平台 TUN 冲突检查和 Windows 内核启动失败诊断，避免与其他 VPN/TUN 客户端争用时只显示通用错误。
- 优化 Android 首次订阅配置准备，复用无需重复生成的编译结果，并记录各启动阶段耗时。

## English

- Added a cat animation card showing the actual VPN state and improved home screen space on mobile and narrow desktop windows.
- Added cross-platform TUN conflict checks and clearer Windows core startup diagnostics when another VPN/TUN client is using the interface.
- Optimized Android first-time subscription preparation by reusing compiled results where possible and logging startup stage timings.
