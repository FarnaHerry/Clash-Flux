# Clash-Flux v0.3.92

## 简体中文

- 代理集合扩展到 HTTP、file、inline 三种来源：file 在显式数据根内只读，inline 从 payload 完整转换；HTTP/file/inline 可混用，HTTP 缓存仍只在完整候选检查通过后提交。
- `use` / `include-all-providers` 支持 `select` 与 `url-test` 组，并接入常见 `filter` / `exclude-filter` / `exclude-type` 子集；provider-backed url-test 输出原生 `urltest`，静态成员和调度差异记近似。
- 应用订阅时先收集全部被引用的代理集合，再下载完整编译后发现的规则集合；代理缓存与规则缓存分别写入各自目录，桌面次来源的 provider 按来源 ID 隔离。
- 手动更新订阅只强制刷新本次来源自己的规则与代理集合；自动更新和导入不再强刷，按各 provider 的 `interval` 复用已验证缓存，避免无关来源被一起更新。
- provider 准备已通过的最终候选检查可被调用方复用；selector 投影或 GEO 重编译改变最终字节时仍重新检查，未准备 provider 的普通配置继续由调用方检查。
- Medium/Expanded 窗口的添加订阅改为弹窗，二维码、文件、URL 和 PPTP 子表单共用弹窗内独立导航栈；Compact 保留页面。HTTP 超时和更新间隔各占一行，二维码扫描页可滚动。
- 修复宽屏添加弹窗把环境节点直接挂到 `DialogCard` 时的挂载崩溃；对话框表面、圆角和内边距改由独立组件承载。
- Android 无 TUN 常驻 libbox 的待命状态可删除无其他引用的主订阅；删除前等待后台停核确认，不把异步重启请求当作旧来源已释放。
- 外部资源页文案明确：远程规则和代理集合会在应用订阅时下载并在手动更新时刷新，页面只展示声明。
- 仍不支持启用的独立 provider 健康检查、非空 override、age 加密、非 DIRECT 下载及 `include-all` 等组合；`include-all-proxies` 与 provider 混用仍拒绝。
- 已验证桌面构建、provider/规则回归、手动订阅更新与 Android Debug Java/NDK 构建；未做 Android 真机外网/VPN、正式签名覆盖安装或 Windows/macOS 实机验收。
- Android versionCode 为 170。

## English

- Proxy providers now cover HTTP, file and inline sources: files are read-only under the explicit data root, inline payloads are fully converted, and the three types can be mixed. HTTP caches still commit only after the complete candidate passes validation.
- `use` / `include-all-providers` now supports `select` and `url-test` groups with the common `filter` / `exclude-filter` / `exclude-type` subset. Provider-backed url-test groups map to native `urltest`; static membership and scheduling differences are reported as approximate.
- Applying a profile first collects every referenced proxy provider, then prepares rule providers revealed by the full compile. Proxy and rule caches use their own directories, and desktop secondary-source providers remain isolated by source ID.
- Manual subscription updates force refresh only that source's own rule and proxy providers. Automatic updates and imports no longer force, reusing verified caches according to each provider's `interval` so unrelated sources are not refreshed.
- Candidate checks completed during provider preparation can be reused by callers; selector projection or a GEO recompile that changes final bytes still triggers a fresh check, and ordinary configurations without providers keep the caller's check.
- Medium/Expanded windows now add subscriptions in a dialog whose independent navigation stack hosts QR, file, URL and PPTP subforms; Compact keeps the page flow. HTTP timeout and update interval each use a separate row, and the QR scanner page scrolls.
- Fixed a mount crash when the wide-window add dialog attached an environment node directly to `DialogCard`; the dialog surface, corners and padding now live in a dedicated component.
- A standby main subscription can be removed on Android when a core-only libbox is running; deletion waits for the background stop acknowledgement instead of treating an asynchronous restart request as proof that the old source was released.
- The external-resources page now explains that remote rules and proxy collections download when a profile is applied and refresh on manual updates, while the page itself only lists declarations.
- Enabled independent provider health checks, non-empty overrides, age encryption, non-DIRECT downloads and `include-all` combinations remain unsupported; mixing `include-all-proxies` with providers is still rejected.
- Desktop builds, provider/rule regressions, manual subscription refresh and Android Debug Java/NDK builds were verified. Android device Internet/VPN behavior, signed upgrade installation and Windows/macOS device testing were not performed.
- Android versionCode is 170.
