## 中文

- 订阅、代理、连接和日志页的搜索收起为放大镜。窄屏展开时占满工具栏，宽屏保留右侧操作，搜索框从图标位置平滑展开。
- 桌面一级侧栏使用黑白交互反馈，首页彩蛋链接和小图标按钮使用圆角反馈。首页流量卡改用中性色，无数据时显示零值。
- 网站测试提供固定站点和单站测速，代理组测速移到节点搜索旁。
- Android 键盘打开时收起底部导航。Windows 托盘运行状态图标使用固定配色。

## English

- Collapse search on the Subscriptions, Proxies, Connections, and Logs pages to a magnifying glass. Search animates from the icon, fills the toolbar in narrow windows, and keeps adjacent actions visible in wide windows.
- Use monochrome feedback in the desktop sidebar and rounded feedback on small icon buttons and Home Easter egg links. Home traffic cards use neutral colors and show zero values before data arrives.
- Website tests offer preset sites and individual tests. Proxy group latency testing sits next to node search.
- Hide bottom navigation while the Android keyboard is open. Use fixed colors for Windows tray status icons.
- Android versionName is 0.3.126 and versionCode is 203.
