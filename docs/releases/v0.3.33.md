# Clash-Flux v0.3.33

## 简体中文

- 订阅配置文本改为保存文件后从本地文件导入；本地文件入口支持拖入，也可点击打开文件选择器。扫码文本仍按内容识别，直接配置入口保留 PPTP 表单。
- 桌面标题栏搜索框会随窗口可用宽度收缩，宽窗口保持 320 逻辑像素上限，窄窗口不再溢出。
- 首页移除公网出口检测卡片，保留本机内网地址；流量图隐藏坐标轴与刻度，让曲线更简洁。
- 修复全局路由规则保存期间继续编辑时改动被覆盖的问题；保存失败会保留当前列表供修正，内核运行时也不再重复执行候选检查。
- Windows PPTP 第二条系统拨号会在停止主内核前被拒绝，并提示当前占用连接；OpenVPN 多连接不受影响。

## English

- Configuration text can now be saved as a file and imported through the local-file flow. The file entry accepts drag-and-drop and still opens the file picker on click. Scanned QR text remains content-detected, and direct configuration keeps the PPTP form.
- Desktop title-bar search fields shrink with the available window width, stay capped at 320 logical pixels on wide windows, and no longer overflow narrow ones.
- Remove the public egress-IP check card from the home page while keeping local LAN addresses; simplify the traffic chart by hiding its axes and tick labels.
- Fix global routing-rule edits being overwritten while a save is in flight. Failed saves keep the current list for correction, and a running core no longer repeats the candidate check.
- Reject a second Windows PPTP system dial before stopping the main core and name the connection that is using the slot. OpenVPN multi-connection is unaffected.
