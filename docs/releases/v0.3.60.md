# Clash-Flux v0.3.60

## 简体中文

- 调整 Windows 安装器升级行为：MSI 将旧版移除纳入安装事务，安装失败时可回滚；安装器以 Burn 的嵌入式静默模式运行时不再创建 HuxerUI 窗口。

## English

- Adjusted Windows installer upgrades: removal of the previous MSI product participates in the install transaction and can be rolled back on failure. The updated bootstrapper no longer creates a HuxerUI window when Burn runs it in embedded/quiet mode.
