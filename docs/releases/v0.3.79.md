# Clash-Flux v0.3.79

## 简体中文

- 调整主题设置：主题模式使用紧凑的横向图标选项；主题颜色改为真实配色预览卡，不显示颜色名称或编码；窄屏添加/编辑颜色进入二级页并使用统一 MD3 输入框。
- 代理节点卡片增加独立测速入口，测速状态跨页面保留；支持单节点测速并统一刷新动画。
- 修复规则页启动时早于数据库加载读取全局规则的问题，并让保存任务在离开页面后继续完成。
- 统一 Windows 与 Linux 的服务内核生命周期和所有权清理；修复 Android 后台服务启动、停止与会话状态竞争，保持已有代理行为。

## English

- Refine theme settings with compact horizontal mode choices and color preview cards showing the actual palette without names or codes. Narrow layouts use a dedicated add/edit page with the shared MD3 input field.
- Add a per-node latency test action. Test state survives page changes, and node tests share the refresh animation.
- Fix global rules loading before database hydration and keep saves running when leaving the rules page.
- Unify Windows and Linux service-owned core lifecycle and cleanup. Fix Android background service start/stop and session-state races while preserving existing proxy behavior.
