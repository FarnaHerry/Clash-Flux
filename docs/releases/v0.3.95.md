# Clash-Flux v0.3.95

## 简体中文

- 修复可能导致虚拟网卡下国内流量落到代理兜底的 DNS 转换缺口：普通 `nameserver-policy` 支持引用已转换的 domain provider，保留规则集与域名策略的声明顺序；托管真实 IP DNS 启用反向映射，让经过内核 DNS 的 IP 连接能够匹配域名规则。原生 JSON 已有 DNS 设置继续保留。
- 新增「网站测试」页面与独立的网页检测图标。宽屏在侧边栏，窄屏在设置「更多」；常用国内外网站以自适应卡片展示 HTTP 状态及耗时，支持全部测试、单卡重试、取消和临时添加地址，最多三个并发请求。
- 桌面订阅及 Provider 文件下载复用客户端的有界空闲连接池，减少重复 DNS/TCP/TLS 建连开销；站点、证书策略、代理、请求头与环境设置隔离，失败仍保留旧订阅和资源缓存。
- 桌面连接详情新增首批编排规则追溯：显示经当前已应用计划与原生实例核验的规则 ID、目标来源和计划版本。历史连接、重复规则描述及未标注的原始规则保持未关联，避免显示猜测结果。
- 外部资源页将不支持或无法识别的内容统一显示为「未识别到外部资源」，移除仅 Clash YAML 支持的格式报错；真实文件读取和刷新失败仍保留错误反馈。
- HuxerUI 更新至固定 fork 提交 `83617e66`（SDK 0.4.0），本地和 CI 使用相同源码。sing-box/libbox 保持 1.14.4；Android versionName 为 0.3.95，versionCode 为 173。
- Lib-SQLite 固定提交更新为 `3b286a2`：原固定提交已不在 fork 远端，配置期取源码会失败。新提交保留启动只读查询与逐值 UTF-8 校验，主键 schema 校验只把单列 `INTEGER` rowid 别名视为非空；应用现有 schema 全部显式声明 `NOT NULL`，不改变持久化行为。
- 验证：本地桌面全目标构建及 31/31 必跑回归通过，覆盖 DNS/TLS、Provider、连接追溯、网站测试 UI、资源管理与持久化；Android Debug Java/NDK 与五项宿主策略回归通过。正式多平台安装包和 APK 签名由标签 CI 核验。
- 边界：网站测试使用当前应用网络，HTTP 响应不代表完整网页加载；Android 应用自身绕过虚拟网卡，不能据此验收其它应用的 VPN 分流。FakeIP 完整语义、节点专用资源 DNS 策略、原始订阅规则追溯和完整 L3 工作仍待补齐。跨平台安装、APK 正式签名及设备网络验收以实际产物和实机结果为准。

## English

- Fixed DNS translation gaps that could send domestic traffic to the proxy fallback under TUN. Ordinary `nameserver-policy` can reference converted domain providers while preserving resource/domain policy order. Managed real-IP DNS now retains reverse mappings so IP connections can match domain rules after resolving through the core. Existing native JSON DNS settings remain authoritative.
- Added a Website Tests page and a dedicated browser/diagnostic icon. Open it from the wide sidebar or Settings → More on compact screens. Adaptive cards show HTTP status and elapsed time, with batch testing, individual retries, cancellation, temporary custom targets and at most three concurrent requests.
- Desktop subscription and Provider file downloads now reuse a bounded per-client idle connection pool to reduce repeated DNS/TCP/TLS setup. Origin, certificate policy, proxy, request headers and environment settings remain isolated; failures preserve existing subscriptions and cached resources.
- Added initial desktop orchestration-rule tracing in connection details: verified rule ID, target source and applied-plan revision are tied to the accepted plan and native instance. Historical connections, duplicate descriptions and unannotated original rules remain unlinked.
- External Resources now shows an unrecognized/empty state for unsupported or unrecognized content instead of the Clash-YAML-only format error. Actual file-read and refresh failures retain their error feedback.
- Updated the pinned HuxerUI fork to `83617e66` (SDK 0.4.0), shared by local builds and CI. sing-box/libbox remains 1.14.4. Android versionName is 0.3.95 and versionCode is 173.
- Moved the pinned Lib-SQLite commit to `3b286a2`; the previous pin no longer exists on the fork remote, so configure-time source fetching failed. The new commit keeps the read-only startup queries and per-value UTF-8 validation, and treats only a single-column `INTEGER` rowid alias as non-null in primary-key schema validation. Every application schema declares `NOT NULL` explicitly, so persistence behaviour is unchanged.
- Validation: the local full desktop build and all 31 required regressions passed, covering DNS/TLS, Providers, connection tracing, Website Tests UI, resource management and persistence. Android Debug Java/NDK and five host policy regressions passed. Tag CI verifies the release packages and APK signature.
- Boundaries: website tests use the current app network, and an HTTP response does not prove a full page loads. The Android app bypasses its own VPN, so these tests do not verify other applications' VPN routing. Complete FakeIP semantics, node-specific resource DNS policies, original-subscription rule tracing and the remaining L3 work are still pending. Cross-platform installation, release APK signing and device networking require the corresponding artifact and device checks.
