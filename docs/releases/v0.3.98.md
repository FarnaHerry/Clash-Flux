# Clash-Flux v0.3.98

## 简体中文

- Android 扫码页增加「从相册选择」，可选择单张图片识别二维码；与相机共用普通 QR 导入和 QRS 帧重组，可以逐张补充 QRS 帧。相机不可用或权限被拒绝时仍可从相册选图。
- 选择图片时暂停相机并取消在途拍照/解码，取消、失败或尚未集齐 QRS 帧后恢复此前扫描；离开页面取消等待，迟到结果不会触发导入。图片通过文件引用交给 Java 工作线程采样解码，避免原文件整份复制到 C++/JNI。
- 直接集成官方 Lib-Media，固定 `f45eb3c`，未创建 fork。arm64 Debug 同条件测量增量为 **2.92 MiB（5.85%）**，包含 Media3 播放器依赖。暂时接受该增量，等待作者计划在 0.4 Release 前完成的 Android 静态链接调整，再复测裁剪效果；详细基线与 TODO 见[二维码扫描](../qr-scanning.md)。
- HuxerUI 更新至 `97d6fed`（SDK 0.4.0），新增受控分栏与单窗口停靠布局 API，现有应用页面兼容。其它既有扩展及 sing-box/libbox 1.14.4 固定版本不变。
- Android versionName 为 **0.3.98**，versionCode 为 **176**。
- 本轮功能与依赖快照已通过桌面全目标构建、**31/31** 必跑回归、QRS **1/1**、Android Debug Java/NDK/APK 构建，并检查 Linux GUI 首页空流量圆环与宽窄窗口往返。真机相册/权限、摄像头恢复、实际导入、内存占用及跨平台安装尚未验收；正式安装包和 APK 签名由标签 CI 核验，本轮按要求不监听 CI。

## English

- The Android QR scanner now offers “Choose from photos” for a single image. Photos and camera captures share QR import and QRS frame assembly, so frames can be added one image at a time. Gallery selection remains available when the camera is unavailable or permission is denied.
- Selecting a photo pauses the camera and cancels pending capture/decoding. Cancellation, errors or incomplete QRS sequences resume previous scanning; leaving the page cancels pending waits and suppresses late imports. A retained file reference is sampled and decoded on a Java worker without copying the entire original file through C++/JNI.
- Integrated official Lib-Media at `f45eb3c` without a fork. The measured arm64 Debug APK increase is **2.92 MiB (5.85%)**, including Media3 playback dependencies. This increase is accepted for now; a TODO tracks the author's planned Android static-linking changes before the 0.4 release, followed by another size comparison. See [QR scanning](../qr-scanning.md).
- Updated HuxerUI to `97d6fed` (SDK 0.4.0), adding controlled split and single-window docking layout APIs while keeping existing application pages compatible. Other existing extension pins and sing-box/libbox 1.14.4 are unchanged.
- Android versionName is **0.3.98**, with versionCode **176**.
- The feature/dependency snapshot passed the full desktop build, **31/31** required regressions, **1/1** QRS test and Android Debug Java/NDK/APK build. Linux GUI checks covered the zero-traffic ring and wide/compact resizing. Device photo selection/permissions, camera recovery, actual imports, memory use and cross-platform installation remain unverified. Tag CI verifies release artifacts and the APK signature; this run does not monitor CI, as requested.
