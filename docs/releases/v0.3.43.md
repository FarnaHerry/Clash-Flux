# Clash-Flux v0.3.43

## 简体中文

- 清理 Windows 服务拆分后的过时管理员权限提示；Linux TUN 仍通过 root 服务运行。
- 连接卡片合并协议与目标地址，展示实时速率和累计流量；新增连接详情页、实时流量图，以及关闭单条或全部连接前的确认。
- 首页流量卡片移除上传/下载文字标签。宽屏首页保留悬浮启动按钮，并在启动后动效展开为状态卡片；手机端移除重复的隧道状态卡片，窄屏使用与断点一致的两列布局。

## English

- Removed obsolete Windows administrator prompts after moving the core into a service. Linux TUN continues to run through the root service.
- Connection cards combine protocol and destination, show current rates and totals, and open a detail page with a live traffic chart. Closing one or all connections now asks for confirmation.
- Removed upload/download labels from the Home traffic card. On wide desktop layouts, the floating start button animates into a status card after startup. Mobile no longer shows a duplicate tunnel status card, and narrow Home layouts use two columns at the compact breakpoint.
