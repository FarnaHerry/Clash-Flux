- 首页宽屏悬浮猫咪向正文让出滚动条槽，保留内容尾部避让且不缩短滚动条轨道。

## English

- Fix the running core's mixed-port snapshot: sing-box's Clash `/configs` reports the mixed inbound as `mixed-port: 0`, so the app no longer overwrites the accepted runtime plan with that value. Home network detection, runtime diagnostics, and subscriptions downloaded through the mixed inbound use the actual listener again.
- Home network detection and website tests now draw country flags from the packaged flag atlas, avoiding Windows text-rendering gaps for regional-indicator emoji. Unknown country codes still use the globe icon.
- Subscription download UA order now presents two complete UA sequences as single choices. Settings uses a secondary page on compact layouts and a focused dialog on wide layouts, showing every UA actually sent by each sequence.
- The wide home floating cat now reserves the scrollbar gutter while keeping content-end clearance, without shortening the scrollbar rail.
- Android versionName is 0.3.118 and versionCode is 196. HuxerUI remains pinned to `d2c9781c`, sing-box/libbox remains 1.14.4, and iOS remains deferred without release assets.
