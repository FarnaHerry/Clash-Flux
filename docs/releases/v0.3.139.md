## 中文

- 修复 Windows 安装器升级卡顿与无关软件文件占用误报：`MajorUpgrade` 调整为 `Schedule="afterInstallExecute"`（在覆盖安装后执行旧版本清理并重用新文件版本对比），在 `platform/windows/app.rc.in` 补充 `VS_VERSION_INFO` 版本资源避免仅按文件名误判冲突，并同步更新 Windows 升级测试与文档。
- 全应用加载与刷新转圈指示器跟随当前强调色及多色调色板：新增 `FluxProgressCircle`（`src/ui/flux_progress_circle.h`）与 `ResolveFluxProgressCircleStyle`，单色主题采用 `theme.colors.primary`，Gemini 四色及自定义多色主题通过径向渐变脉冲圆弧呈现多色加载动效并在后台窗口或减弱动态效果下自动暂停；覆盖代理测速、订阅刷新/PPTP 连接/导入/扫码、外部资源、规则集、网络可见应用及关于页更新提示等全部入口。
- 升级多色与自定义主题算法并支持指定主色：基于 OKLCH 感知色空间统一明度与彩度裁剪，多色中心底色与 Switch 等单色角色统一锚定所选主色；`"gemini"` 预设收敛至同一套派生与主色索引机制（`primaryIndex = 2`）；在添加/编辑颜色表单的多色模式下新增「设为主色」按钮与主色圆点标记（支持 `@<index>` 向后兼容持久化与主题预览开关联动），补充相关 i18n 词条，并修复编辑页点击已有色块切换时引发 `TextField value is invalid` 的悬空引用问题。
- 修复 iOS Simulator 构建中 `DesktopRefreshProfilesDueOnce` 在 `!defined(__ANDROID__)` 条件下声明缺失的问题。
- Android versionName 为 0.3.139，versionCode 为 216。

## English

- Fixed Windows installer upgrade hangs and false `FilesInUse` prompts from unrelated software sharing OpenSSL DLL names: switched `MajorUpgrade` to `Schedule="afterInstallExecute"` in `Package.wxs.in`, added `VS_VERSION_INFO` resources in `app.rc.in` for proper versioned file comparison, and updated the Windows upgrade test and docs.
- Synchronized all loading and refresh circular spinners with the active accent color and multi-color palettes: introduced `FluxProgressCircle` (`src/ui/flux_progress_circle.h`) and `ResolveFluxProgressCircleStyle` so monochrome themes use `theme.colors.primary` while Gemini 4-color and custom multi-color themes render radial-gradient pulsing arcs (pausing in background windows and reduced motion) across proxy speed tests, profile refresh/PPTP/import/QR scanning, external resources, rule sets, network app loading, and About update rows.
- Upgraded custom and multi-color theming to unified OKLCH perceptual normalization with primary-anchored center bases and primary stop selection: consolidated the `"gemini"` preset (`primaryIndex = 2`) onto the shared OKLCH derivation path, added "Set as primary" controls and indicator dots for multi-color mixes in `ThemeColorEditor` (with backward-compatible `@<index>` serialization and live switch preview updates), updated localization catalogs, and fixed a use-after-move bug when selecting existing color stops that caused `TextField value is invalid`.
- Fixed iOS Simulator compilation by adjusting the `#if !defined(__ANDROID__)` guard for `DesktopRefreshProfilesDueOnce`.
- Android versionName is 0.3.139 and versionCode is 216.
