# Clash-Flux v0.3.89

## 简体中文

- 修复 `default_mode=direct/global` 时 libbox 的可选模式列表可能缺少 `rule`，导致无法切回规则模式并持续直连的问题。
- 编译器在全部策略规则末尾追加与 `route.final` 等价的 `clash_mode=rule` 兜底，确保规则、全局、直连三种模式始终可选，同时不改变原路由出口、首个有效 MATCH 或显式 REJECT 语义。
- 增加真实 sing-box 运行回归：以默认 `direct` 的生产编译配置启动，再切换并回读确认 `rule`；保留缓存模式恢复与桌面/Android 共用编译器回归。
- Android versionCode 为 167。

## English

- Fixed an issue where libbox could omit `rule` from its available mode list when `default_mode` was `direct` or `global`, preventing a switch back to rule mode and leaving traffic on the direct outbound.
- The compiler now appends a semantically neutral `clash_mode=rule` fallback using `route.final` after all policy rules. Rule, global and direct remain available without changing the original final outbound, first matching MATCH rule or explicit REJECT behavior.
- Added a real sing-box runtime regression that starts from the production compiled configuration with default `direct`, switches to `rule` and confirms it through readback, while preserving cached-mode and shared desktop/Android compiler coverage.
- Android versionCode is 167.
