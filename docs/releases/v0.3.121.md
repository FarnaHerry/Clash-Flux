## 中文

- Linux 托盘在原位置更新图标和菜单。切换简版与完整菜单、更新订阅和代理组时，保留同一个托盘项。
- 代理页每个节点独立显示测速状态。扩大并圆角化延迟数字的悬停区域，测速动画期间隐藏悬停反馈。
- 已有悬停反馈的卡片统一使用 1px 描边，普通卡片默认隐藏描边。悬停首页卡片里的按钮或输入框时，外层卡片描边仍然可见。
- Android versionCode 为 199。

## English

- Update the Linux tray icon and menu in place. Keep the same tray item when switching between the startup and full menus or when profiles and proxy groups change.
- Show speed-test state independently for each proxy node. Give latency values a larger, rounded hover area and suppress hover feedback while the test animation runs.
- Use a consistent 1px outline for existing card hover feedback and hide it on idle, unselected cards. Home cards retain their outline while a nested button or field is hovered.
- Android versionCode is 199.
