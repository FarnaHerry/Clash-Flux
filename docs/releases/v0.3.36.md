# Clash-Flux v0.3.36

## 简体中文

- 安装器深色模式自适应：跟随系统深浅色自动切换，颜色直接取自主应用同一套产品配色（品牌水蓝 + 中性灰阶），标题栏、品牌侧栏与按钮两态一致。
- 修复升级时反复弹出「已安装新版本」页面的根因：升级流程驱动的嵌入式旧版本卸载此前被新版本检测拦下、静默退出且不注销注册，导致 bundle 注册跨版本累积（实测单个产品攒了七个旧条目、每次升级逐条弹页）。命令驱动的安装/卸载现在绕过该交互闩锁、自行收尾并按最终状态映射退出码，交互式运行保留原保护。
- 命令驱动的卸载保留引擎停止与 bundle 注销：即使 MSI 组件缺失也能清理注册，不再遗留孤儿条目。
- iOS 模拟器编译链修复（非阻塞门禁自 v0.3.29 起持续红灯，本轮逐层打通）：CI 改单架构 arm64（C++20 std 模块编译器限制）、框架 link.rsp 补齐应用侧三方静态库与平台框架依赖、Packet Tunnel 扩展不再强制载入主程序归档。
- HuxerUI 框架固定版本升级到 `8fd9d0e`（含上述安装器与 iOS 框架修复）。

## English

- The installer now adapts to dark mode: it follows the system light/dark preference and uses the exact same product palette as the main app (brand water-blue plus neutral grays), keeping the title bar, branding panel and buttons consistent in both modes.
- Fixed the root cause of the "a newer version is installed" page popping up repeatedly during upgrades: the embedded uninstall of previous bundles driven by the upgrade flow was previously stopped by the newer-version detection, exiting silently without unregistering, so bundle registrations accumulated across releases (observed: seven stale entries for one product, one page per stale entry on every upgrade). Command-driven installs/uninstalls now bypass that interactive gate, finish on their own and map the terminal status to the exit code; interactive runs keep the original protection.
- Command-driven uninstalls keep engine shutdown and bundle unregistration: the registration is cleaned up even when the MSI component is missing, leaving no orphan entries behind.
- iOS Simulator build chain fixes (the advisory gate had been red since v0.3.29; unblocked layer by layer this cycle): CI builds a single arm64 slice (a C++20 std-module compiler limitation), the framework link.rsp now resolves the app target's own transitive dependencies (third-party static libraries plus platform frameworks), and the Packet Tunnel extension no longer force-loads the main app archive.
- The pinned HuxerUI framework is updated to `8fd9d0e` (carrying the installer and iOS framework fixes above).
