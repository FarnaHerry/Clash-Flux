# Clash-Flux v0.3.52

## 简体中文

- 订阅卡片支持拖动排序：每张订阅卡新增拖动手柄，拖动预览持续跟随原始抓取点，滚动网格视口也注册了拖放目标（卡片间隙和视口边缘可继续触发排序与边缘自动滚动）；松手后按最终顺序落库（`profiles.order`），重启后保留，取消或失败自动回滚原顺序。
- 订阅到期时间：解析 `subscription-userinfo` 响应头的 `expire` 字段，订阅卡片与首页显示「到期时间 YYYY-MM-DD」；数据库 schema 升级到 v2（profiles 追加 `expire_at` 列，事务内迁移，老数据全部保留）。
- 不限量订阅的流量展示：`total` 未知时卡片与首页显示「已用 X / 不限量」，进度条以「满」呈现，不再整行隐藏。
- 订阅卡片的「更新于」改为相对时间（刚刚 / N分钟前 / N小时前 / N天前 / N个月前 / N年前），更新时刻更直观。
- 首页卡片标题图标规范化：所有首页卡片左上角配备契合语义的专属图标（20pt、主题色着色，规范已写入 AGENTS.md）。
- 首页「当前订阅」卡重构：标题直接显示订阅名，不再放「当前订阅」标签；仅在解析到流量数据时显示流量行，到期行只在订阅提供时出现。
- 进度条样式修复：去掉 Material 3 自带的分段轨道间隙与末端停止圆点，恢复连续平滑的线性进度条。
- 远程订阅名称兜底改进：导入/更新未填名称时用 URL 主机名（去掉 `www.`、凭据与端口）作为可读名称，不再用整条 URL；编辑订阅留空名称时保留原名称。
- PPTP 来源不再显示「配置保真度」菜单项（无对应可编译订阅）。
- Windows：服务未安装时启动/重启内核返回明确的不可用状态，不再走失败路径；服务启动后最长等待 15 秒确认管道可达，修复启动竞态误报。
- Windows 服务自更新信任链增强：受保护根目录除 Program Files 外接受 Program Files (x86) 与实际安装根，ACL 校验接受安装用户 SID 作为受信 owner，升级源与更新器副本逐级复核。
- 连接详情图表的总上传/总下载数字也带上 ↑/↓ 方向，与速率列对齐易读。
- 订阅刷新图标与溢出菜单图标统一为 20pt 视觉尺寸。

## English

- Subscription cards now support drag-to-reorder: each card has a drag handle, the drag preview keeps following the original grab point, and the scrolling grid viewport registers drop targets (gaps and viewport edges keep reordering working with edge auto-scroll). Dropping persists the final order (`profiles.order`), which survives restarts; canceling or failures roll back automatically.
- Subscription expiry: the `expire` field of the `subscription-userinfo` header is now parsed; profile cards and the home page show "Expires YYYY-MM-DD". The database schema moves to v2 (profiles gains an `expire_at` column via an in-transaction migration that keeps all existing data).
- Unlimited-plan traffic display: when `total` is unknown, cards and the home page show "Used X / unlimited" with the progress bar rendered full, instead of hiding the traffic row entirely.
- The profile card's "updated at" line now uses relative time (just now / N minutes ago / N hours ago / N days ago / N months ago / N years ago).
- Home page card headings now all carry a semantic icon in the top-left corner (20pt, primary-tinted; the rule is documented in AGENTS.md).
- The home "current subscription" card was reworked: the title is the subscription name itself (no more label), the traffic line only appears when usage data was parsed, and the expiry line only shows when the subscription provides one.
- Progress bar style fix: Material 3's segmented track gap and end stop dot are removed, restoring a continuous smooth linear progress bar.
- Better remote-subscription name fallback: when importing/updating without a name, the URL host (stripped of `www.`, credentials and port) is used instead of the whole URL; editing with an empty name now keeps the existing name.
- PPTP sources no longer show the "Configuration fidelity" menu entry (there is no compilable subscription to inspect).
- Windows: starting/restarting the core without the service installed now reports a clear unavailable status instead of a failure path; after service start the pipe is polled for up to 15 seconds, fixing a startup race that misreported unreachability.
- Windows service auto-update trust chain hardening: protected roots now accept Program Files (x86) and the actual install root in addition to Program Files, the ACL check accepts the installing user's SID as a trusted owner, and the upgrade source and updater copy are re-validated level by level.
- The connection details chart's total upload/download numbers now carry the ↑/↓ direction, aligned with the rate column.
- The subscription refresh and overflow menu icons now use a consistent 20pt visual size.
