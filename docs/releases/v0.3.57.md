# Clash-Flux v0.3.57

## 简体中文

- 修复 Linux 托盘轻量模式退出主窗口后仍保留窗口对象和 GTK 资源的问题；重复隐藏与重新打开现在会回收旧窗口。
- 修复 GTK 窗口直接销毁时输入法上下文清理顺序错误，以及线程退役请求与应用退出之间的竞争。

## English

- Fixed Linux lightweight tray mode retaining retired window objects and GTK resources. Repeated hide and reopen cycles now release the old window.
- Fixed input method cleanup ordering when a GTK window is destroyed directly, and a race between window retirement requests and application shutdown.
