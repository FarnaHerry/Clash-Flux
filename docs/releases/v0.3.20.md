# Clash-Flux v0.3.20

## 简体中文

- 完善 Clash 订阅解析和 sing-box 配置编译：扩展 DNS hosts、域名策略与加密 DNS 参数支持，补充 HTTP/MRS 规则集缓存、校验和失败回滚，保留未知字段和订阅语义的明确边界。
- 优化大型订阅准备流程：减少 MRS 规则展开时的中间对象与重复配置编译，避免规则集输入没有变化时重复检查。
- 完善桌面多来源策略编辑、订阅导入反馈、代理分区导航与设置体验；Android 订阅链接激活和后台状态同步也得到修复。
- 加强订阅持久化保护、旧数据库迁移和运行时回归；桌面 CI 将 15 项必跑测试纳入发布门禁。

## English

- Improve Clash subscription parsing and sing-box configuration compilation, including DNS hosts and encrypted DNS options. Add HTTP/MRS rule-provider cache validation and failure rollback while keeping explicit fidelity boundaries for subscription input.
- Reduce intermediate objects when expanding large MRS rule sets and avoid repeated configuration compilation and checks when rule-set inputs have not changed.
- Improve desktop multi-source policy editing, subscription import feedback, proxy section navigation, and settings. Fix Android subscription-link activation and background state synchronization.
- Strengthen subscription persistence, legacy database migration, and runtime regression coverage. Desktop CI now gates releases on 15 required tests.
