# Clash-Flux v0.3.84

## 简体中文

- 修复 Android VPN 在部分多网络/双卡设备上已授权但无流量的问题：选择物理上游网络时要求系统声明 `INTERNET` 能力，并优先使用已通过验证的默认网络，避免把无数据的副卡或临时网络当成上游。
- 记录 Android 网络候选和最终选择的接口，默认物理接口注册增加短时重试；出现问题时可在日志页看到实际选中的 `wlan`/`rmnet` 接口。
- Android versionCode 为 162；其余平台行为不变。

## English

- Fix Android VPN sessions that were authorized but carried no traffic on some multi-network and dual-SIM devices. Physical upstream selection now requires the system `INTERNET` capability and prefers a validated network, avoiding dormant SIM or transient networks.
- Log Android network candidates and the selected interface, and retry default-interface registration briefly. The logs page now shows the actual `wlan`/`rmnet` interface used.
- Android versionCode is 162; other platforms are unchanged.
