## 中文

- 首页将实时下载和上传拆成两张卡片，分别用向下和向上箭头显示实时速率与历史曲线。
- 修复窄屏设置页「日志级别」和「复制环境变量」的文字换行。空间不足时，下拉框整体移到下一行，复制图标仍紧跟标题。
- 为添加订阅的本地文件选区补上默认虚线描边，并将代理组测速图标替换为四角星。
- Windows 安装器采用自定义标题栏，显示 Windows 报告的占用应用，并在 Restart Manager 支持时尝试正常关闭占用进程。仍有占用可从托盘退出应用后重试。
- HuxerUI 固定版本更新至 `b88c4d1f`，含安装器修复和 ComboBox 点按重新打开候选列表的修复。
- Android versionName 为 0.3.125，versionCode 为 202。

## English

- The Log level and Copy environment variables labels stay on one line in narrow Settings layouts. The dropdown moves below the label when needed, and the copy icon stays next to its label.
- Add a default dashed outline to the local subscription file picker and use a four-point star for proxy-group latency tests.
- The Windows installer uses a custom title bar, names applications reported as holding files open, and requests a graceful shutdown when Restart Manager supports it. If Clash-Flux is still running, quit from the system tray and retry.
- Update the pinned HuxerUI revision to `b88c4d1f`, including the installer fixes and tap-to-reopen behavior for ComboBox suggestions.
- Android versionName is 0.3.125 and versionCode is 202.
