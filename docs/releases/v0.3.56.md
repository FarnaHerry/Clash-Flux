# Clash-Flux v0.3.56

## 简体中文

- 修复 PPTP / OpenVPN 附加连接的状态更新与重复操作：连接期间禁用重复任务，更及时同步状态；已连接的 PPTP 不会被重复拨号。
- 附加连接成功后，如果 sing-box 主内核已停止，会自动启动主内核，减少连接完成后还要回首页手动启动的步骤。
- 增加托盘轻量模式：窗口隐藏到托盘时销毁主界面，之后从托盘重新打开；托盘菜单更新仅在内容变化时重建，并提供该模式的开关。
- Android 常驻通知现在可以点击打开应用并进入设置页的后台保活区域。
- 桌面 Pager 支持触控板连续横向翻页，跨窗口拖放操作也由应用级运行时维护。

## English

- Improved PPTP / OpenVPN auxiliary connection status and duplicate-action handling: repeated actions are disabled while connecting, status updates arrive sooner, and an already connected PPTP session is not dialed again.
- After an auxiliary connection succeeds, the main sing-box core starts automatically when it was stopped, removing the extra step of returning Home to start it.
- Added lightweight tray mode: hiding to the tray retires the main window and UI, which are recreated when opened again. Tray menus are rebuilt only when their contents change, and the mode can be toggled from the tray menu.
- The Android persistent notification now opens the app and navigates to the background keep-alive area in Settings when tapped.
- Desktop Pager now supports continuous horizontal trackpad navigation, and cross-window drag operations are maintained by the application runtime.
