# Clash-Flux v0.3.39

## 简体中文

- Windows 安装器分页细化：重新打开同一版本的安装包现在进入「此版本已经安装」维护页（主操作「重新安装并保留数据」，修复/卸载次级），检测到旧版本才显示独立升级页（主操作「升级并保留数据」）——不再共用一页，也不会把同版本误读成升级。
- 日志列表更紧凑：卡片圆角收紧到 4pt 的同时，行间距与行高估算同步下调，密集档的圆角与间隙保持同一密度档（该联动规则已写入仓库开发规范）。

## English

- The Windows installer pages are refined: reopening the installer for the version already installed now lands on a dedicated "this version is already installed" maintenance page (primary action "Reinstall and keep data", with repair/uninstall secondary), while an older existing installation shows a separate upgrade page (primary action "Upgrade and keep data") — no more one shared page and no same-version reads as an upgrade.
- The log list is denser: alongside the card corner tightening to 4pt, the row gap and row-height estimates moved down together, keeping the dense tier's radius and gap at the same density step (the coupling rule is now recorded in the repository development guide).
