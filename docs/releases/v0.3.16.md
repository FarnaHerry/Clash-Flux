# Clash-Flux v0.3.16

## 简体中文

- 统一二级分页边距与卡片网格间距：每页两侧使用半份卡片间距，滑动时相邻页面自然合成一份间距，保留满宽跟手效果并消除卡片粘连。

## English

- Align secondary page insets with card grid spacing. Each page uses half a card gap on either side, so adjacent pages combine into one card gap while swiping, keeping full-width tracking and preventing cards from sticking together.
