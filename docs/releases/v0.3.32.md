# Clash-Flux v0.3.32

## 简体中文

- OpenVPN `.ovpn` 与 Clash YAML、sing-box JSON 共用远程订阅、本地文件和配置文本入口，自动识别格式；新建界面移除独立 OpenVPN 类型。普通 `.ovpn` 可作为主来源，桌面也可通过启用的编排规则作为次来源。已有 OpenVPN 记录保留原 ID、凭据、内网路由和辅助连接行为。
- PPTP/OpenVPN 连接卡片在每项连接或断开操作结束后立即更新，不再等待后台轮询或整批操作完成。
- 对尚未转换的 OpenVPN 指令、外部文件和脚本明确报错并列入保真度记录，避免静默忽略。

## English

- OpenVPN `.ovpn` shares the remote subscription, local file and pasted configuration paths with Clash YAML and sing-box JSON, with automatic format detection. The separate OpenVPN creation type is removed. An ordinary `.ovpn` can be the main source or a rule-driven secondary source on desktop. Existing OpenVPN records retain their IDs, credentials, private routes and auxiliary connection behavior.
- PPTP/OpenVPN connection cards update as each connect or disconnect operation finishes, without waiting for the background poll or the entire batch.
- OpenVPN directives, external files and scripts that have not been translated are reported as unsupported instead of being silently ignored.
