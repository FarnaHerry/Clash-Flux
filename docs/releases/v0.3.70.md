# Clash-Flux v0.3.70

## 简体中文

- 订阅规则支持独立的个人修改，更新订阅时保留；修改直接编译为 sing-box JSON，不改写订阅原文。
- 新增共享规则集资源库，支持远程 JSON/SRS 和本地 JSON；个人规则与全局规则都可引用。桌面支持导入本地 SRS 并转换为可编辑 JSON。
- 桌面可手动重新下载远程规则集并重启内核应用；未运行或未引用时只排队，不显示为已下载。
- HuxerUI 集成版本更新到 `3a6c18e`。
- 补充规则集缓存隔离、失败回滚和 TLS 拒绝回归测试。
- Windows 已知问题：从 v0.3.69 升级到 v0.3.70 时，旧 MSI 会删除 `ClashFluxService`。升级后请在“设置 → 内核服务”重新安装/更新服务。

## English

- Add per-subscription personal rule edits that survive subscription refreshes and compile directly to sing-box JSON without rewriting source files.
- Add a shared rule-set library for remote JSON/SRS and local JSON. Personal and global rules can reference these sets. Desktop can import local SRS and convert it to editable JSON.
- Desktop can manually download a remote rule set and restart the core to apply it. When the core is stopped or the set is unreferenced, the request is queued instead of reported as downloaded.
- Update the pinned HuxerUI integration to `3a6c18e`.
- Add regression coverage for rule-set cache isolation, failed updates, and TLS rejection.
- Known Windows issue: upgrading from v0.3.69 to v0.3.70 removes `ClashFluxService` through the previous MSI. Reinstall or update the service from Settings → Core Service after upgrading.
