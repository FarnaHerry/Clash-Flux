# Clash-Flux v0.3.47

## 简体中文

- 修正首页宽屏启停动画时序：点击启动后立即从按钮展开到状态卡片，内核在卡片中加载；点击停止后立即反向收回到按钮。

- Fixed the timing of the wide Home start/stop transition: starting immediately expands the button into the status card, where the core loads; stopping immediately reverses the animation back to the button.
