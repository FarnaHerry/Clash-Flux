# Clash-Flux v0.3.24

## 简体中文

- 设置页增加独立的主题与语言页面。手机端从设置列表进入对应页面，桌面端可在弹窗中选择语言；二级设置页只替换内容区域。
- 主题支持自动、深色和浅色模式，并可从预设主题色中选择或添加自定义颜色。自定义颜色会保存，并在启动时应用。
- 设置条目补充图标，托盘菜单语言与应用同步；首页卡片顶部和左右留白统一为卡片间距。

## English

- Settings now has dedicated theme and language pages. On mobile, open each page from the settings list; on desktop, choose a language from a dialog. Secondary settings pages replace only the content area.
- Choose automatic, dark or light appearance, then select a preset theme color or add a custom color. Custom colors are saved and applied at startup.
- Settings items now include icons, tray menu language follows the app, and home card spacing is consistent at the top and sides.
