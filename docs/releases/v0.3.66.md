# Clash-Flux v0.3.66

## 简体中文

- 首页加载骨架与就绪卡片共用同一套固定网格（`src/ui/home_grid.h/.cpp`）：卡片目录、跨度、`Card` 外壳完全一致，加载态只替换卡片内部内容为占位，不再使用独立的通用等高自适应骨架。
- 加载前后首页保持同一页面骨架、滚动容器与留白：桌面 7 张、移动端 5 张固定基础卡，行高 88pt、卡间距 12pt，两行卡高 188pt，流量卡宽占两列；已知运行中的桌面控制卡保留相同尾部槽位。
- 新增回归：`test_page_transition` 校验加载骨架在 320/960/1400 宽度下与就绪态网格的几何一致性。

## English

- The home loading skeleton and the ready cards now share one fixed grid (`src/ui/home_grid.h/.cpp`): identical card catalog, spans and `Card` shell — the loading state only swaps the card interiors for placeholders instead of using a separate generic equal-height adaptive skeleton.
- The home page keeps the same scaffold, scroll container and padding before and after loading: 7 fixed cards on desktop and 5 on mobile, 88pt rows, 12pt gap, 188pt for two-row cards, traffic card spanning two columns; a known-running desktop control card keeps the same trailing slot.
- New regression: `test_page_transition` verifies the loading skeleton matches the ready grid geometry at 320/960/1400 widths.
