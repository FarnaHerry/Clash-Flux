# Clash-Flux v0.3.74

## 简体中文

- 手机订阅页改为跨来源统一列表；窄屏订阅卡压缩高度并保留一致的信息槽位，代理页显示原始节点名。
- 窄屏编辑页的保存操作固定在底部并统一为 40pt；修复桌面窄窗编辑订阅信息时崩溃及编辑页仍显示底部导航的问题。
- 策略组选择菜单复用统一卡片选中样式，减少订阅更新失败提示重复出现的情况。
- 首页普通卡片增加双击翻面彩蛋，带抬起、侧边与明暗变化，再次双击翻回；背面完整隔离正面控件命中，启动猫咪控制卡不参与，背面暂为空白。

## English

- Show all subscription sources in one list on phones, use shorter subscription cards on narrow screens, and display original proxy names without source prefixes.
- Keep narrow-screen save actions pinned to the bottom at a consistent 40pt height. Fix a crash when editing subscription details in a narrow desktop window and hide the desktop bottom navigation while an edit page is open.
- Reuse the shared selectable-card appearance in strategy-group menus and reduce repeated subscription-refresh failure notices.
- Add a double-click/tap flip Easter egg to ordinary home cards, with lift, edge and lighting effects. The back blocks hidden front controls and accepts another double-click/tap to flip back. The startup cat control is excluded, and the back remains blank for now.
