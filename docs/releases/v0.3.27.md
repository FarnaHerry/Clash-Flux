# Clash-Flux v0.3.27

## 简体中文

- Android 订阅和 HTTP 规则集下载校验响应是否完整；规则集响应体中断时自动重试一次，减少移动网络波动导致的导入失败。
- 修正分享二维码的标准留白，提升扫码识别率。
- 修正手机系统状态栏和导航栏底色，避免页面切换时露出白色背景。

## English

- Android subscription and HTTP rule-set downloads now verify response completeness. Interrupted rule-set bodies are retried once to reduce import failures on unstable mobile networks.
- Added the standard quiet zone around shared QR codes to improve scanning reliability.
- Matched Android system status and navigation bar colors to the page background to prevent white flashes during transitions.
