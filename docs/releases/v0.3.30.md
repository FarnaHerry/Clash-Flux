# Clash-Flux v0.3.30

## 简体中文

- Windows PPTP 引擎状态现在会持续同步。服务安装、更新或重启后，无需重启应用即可恢复连接；刷新能力状态不会重置现有连接或路由。
- CMake 最低版本升级到 4.4，通用第三方库改由锁定来源和校验值的 CPS 包管理配置；HuxerUI 与平台专属构建流程继续沿用项目固定版本。
- 托盘图标扩大并提供矢量源图，更新高分辨率资源。

## English

- Windows now keeps PPTP engine availability in sync. Connections can recover after service installation, update or restart without restarting the app, and refreshing availability does not reset existing connections or routes.
- The minimum CMake version is now 4.4. General third-party libraries use CPS package configuration with pinned sources and checksums, while HuxerUI and platform-specific build flows retain their existing pinned integration.
- Tray icons are larger, with an SVG source and refreshed high-resolution assets.
