## English

- Bare node subscriptions resolve proxy destination domains remotely by default. Local resolution is inserted only when rules need destination IPs, with CIDR `no-resolve` semantics preserved. Verifiable simple rule sets can be matched inline; unsafe conversions are recorded as unsupported.
- Subscription settings add optional remote DoH and a DNS override switch. Older settings without the new fields continue to load with defaults.
- Subscription downloads use the `sing-box` user agent by default, falling back to `clash.meta` and then `clash-flux` after HTTP 403.
- Subscription response caching is bound to subscription ID, URL, request user agent, source version, and body. The first refresh during migration performs a full GET before recording validators.
- The proxy grid bounds its virtual scroll cache to reduce wide-window scrolling stalls.
- HuxerUI remains pinned to `89359f43`, the version that passed the previous complete release matrix. The `e2afd8a3` candidate failed to compile on macOS; its framework fix will be handled in the HuxerUI fork.
- Android versionName is 0.3.114 and versionCode is 192. iOS remains deferred without release assets.
