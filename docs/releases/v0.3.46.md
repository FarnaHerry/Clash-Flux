# Clash-Flux v0.3.46

## 简体中文

- 修复首页宽屏模式下启动内核时的共享过渡动画：按钮先移动到状态卡片中心，再展开；停止时按相反顺序收回。
- 加强 Android Release 签名门禁：只接受正式发布证书，并验证 v1、v2 签名，缺少发布密钥时阻断打包。

## English

- Fixed the shared transition when starting the core on the wide Home layout: the button moves to the status card center before expanding, then reverses that sequence when stopping.
- Strengthened Android Release signing gates: require the official release certificate, verify v1 and v2 signatures, and fail packaging when the release keystore is missing.
