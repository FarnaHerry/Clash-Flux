# Clash-Flux v0.3.55

## 简体中文

- 桌面首页、托盘和 CLI 停止时会核验应用代理、主内核及 PPTP 连接的清理结果；未能确认清理完成时返回失败原因。
- 设置页分区和订阅规则、全局路由规则列表改用密集卡片，减少列表占用空间。
- Windows 构建目录自动携带匹配的 OpenSSL DLL，避免被 PATH 中其他 OpenSSL 版本抢先加载而无法启动。

## English

- Desktop Home, tray, and CLI stop actions now verify cleanup of the app-owned system proxy, core, and PPTP sessions, and report failures when cleanup cannot be confirmed.
- Settings sections and subscription/global routing rule lists now use dense cards to reduce list footprint.
- Windows build-tree output now includes matching OpenSSL DLLs, preventing another OpenSSL version on PATH from breaking startup.
