# Clash-Flux v0.3.28

## 简体中文

- 手机与桌面窄窗口的胶囊导航改为半透明卡片色，选中项平滑滑动；点击时轻微回弹，并移除图标按钮的按压高亮。
- 订阅搜索栏在窄屏占满可用宽度，加号移入胶囊右侧；新建订阅与添加配置页面的标题居中，导入操作放到标题栏右侧。

## English

- The capsule navigation now uses a translucent card surface on phones and narrow desktop windows, with a smoothly moving selection indicator and a subtle click spring. Press highlights have been removed from the navigation items.
- The subscription search field fills the available width on compact screens, with the add action inside its trailing edge. Create-subscription and add-configuration titles are centered, with import actions in the header.
