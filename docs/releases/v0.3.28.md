# Clash-Flux v0.3.28

## 简体中文

- 修复规则页严重卡顿：升级 HuxerUI fork，消除深层拉伸布局对 Grow 子树的重复测量；订阅规则一次发布快照，缓存筛选索引，隔离内核运行统计引起的重复重建。

- 配置保真度改为每个配置的独立页面，从卡片右键或更多菜单进入，只读检查该配置并完整展示记录与错误。

- 日志页合并应用与内核日志，统一按时间展示、搜索、筛选、导出和清空，移除来源标签。

- 所有页面的内容容器延伸到视口底边（不再保留桌面底部外边距）；胶囊导航参考 Telegram 的纯色回退表面，使用独立浮层色、细描边和轻阴影，选中底板使用淡主色、文字与图标使用主题主色，选中项平滑滑动，点击时轻微回弹，并移除图标按钮的按压高亮。
- 订阅搜索栏在窄屏占满可用宽度，加号移入胶囊右侧；新建订阅与添加配置页面的标题居中，导入操作放到标题栏右侧。
- 首页新增「内网 IP」与「网络检测」卡片：前者列出本机局域网 IPv4，后者显示公网出口 IP（内核运行时经代理出口测量），支持手动重新检测。系统代理与 TUN 卡片换新图标，系统代理卡片移除说明小字。

## English

- Fix severe rules-page stalls by upgrading the HuxerUI fork to avoid repeated measurements of deeply nested stretching layouts; large rule lists also use snapshot updates and cached filter indices, with runtime statistics isolated from page rebuilds.

- Each configuration now has a dedicated fidelity page, opened from its context or more menu, with a read-only check of that configuration and the full report or errors.

- Application and core logs now share one chronological list with unified search, filtering, export and clearing; source tabs have been removed.

- Page content containers now extend to the bottom edge of the viewport on every page (the desktop bottom margin is gone); the floating speed-test button on the proxies page gets its own scroll tail clearance. The capsule navigation now uses a Telegram-inspired solid fallback surface with a distinct navigation color, a thin border and a subtle shadow on phones and narrow desktop windows, with a faint primary-color selection background, primary-colored selected icons and labels, and a smoothly moving selection indicator and a subtle click spring. Press highlights have been removed from the navigation items.
- The subscription search field fills the available width on compact screens, with the add action inside its trailing edge. Create-subscription and add-configuration titles are centered, with import actions in the header.
- The home page gains "LAN IP" and "Network Check" cards: the former lists local IPv4 addresses, the latter shows the public egress IP (measured through the proxy while the core is running) with manual re-check. The system proxy and TUN cards get new icons, and the system proxy card drops its caption.
