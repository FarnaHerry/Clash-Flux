## English

- HuxerUI is pinned to `ada3acd`, including upstream window-API convergence, unified task waiting and resumption, system tasks, UIScene multi-window support, persistent external-file access, bitmap snapshots, and runtime diagnostics controls. The fork also fixes the macOS `MacUiWindow` class scope.
- The home network-check card now shows the public egress IP and its country flag emoji. The foreign endpoint falls back to a domestic endpoint; both return the IP and country code. The home LAN card shows only the interface and address selected by the default route.
- The DNS settings entry and save action wait for settings hydration. Subscription user-agent order remains selectable in settings and shows the complete UA sequence currently sent.
- Android launcher shortcuts and the Quick Settings tile use a transparent trampoline, read the live runtime owner, and then start or stop accordingly. A new QR shortcut opens the scanner/import flow once profiles are ready.
- The Android download bridge now fails explicitly when a 304 arrives after dropping user-agent validators, instead of reusing the previous representation.
- Android versionName is 0.3.117 and versionCode is 195; sing-box/libbox remains 1.14.4. iOS remains deferred without release assets.
