# v0.3.109

- 更新 HuxerUI 固定源码至 `5c84b4ab`，合入上游 Row/Column 布局优先级功能；保留已有 Pager、窗口和扩展修复，应用现有布局行为不变。
- 优化订阅刷新：Provider 并发上限提高至 8，统一主订阅、规则集和代理集合的下载策略与条件缓存；304 继续检查依赖并保留未返回的订阅元数据。
- Android 下载直接流式写入独占暂存文件，减少完整正文在 Java/JNI 之间的复制；兼容重试有明确用途、次数与大小边界。
- 分层复用来源解析、资源转换和已检查编译结果；减少网络阶段持锁时间，提交前重新核对来源、设置与运行计划，过期结果拒绝提交。
- 增加逐资源耗时、重试次数与失败分类诊断，失败保留原订阅文件、引用和运行配置。
- 删除订阅“允许无效证书”选项，下载始终校验证书链和主机名；保留旧数据库兼容列，不清理用户订阅。
- Android versionName 为 `0.3.109`、versionCode 为 `187`。此版本没有 Kitty 真机新旧耗时对照数据，不承诺具体提速倍数；iOS 仍暂缓且不提供发布资产。

## English

- Update the pinned HuxerUI source to `5c84b4ab`, merging upstream opt-in Row/Column layout priorities while preserving the existing Pager, window and extension fixes. Existing application layouts retain their behavior.
- Improve subscription refreshes with up to eight concurrent provider downloads and common bounded policies and conditional caches for primary subscriptions, rule providers and proxy providers. A 304 still checks dependencies and preserves omitted subscription metadata.
- Stream Android downloads into exclusive staging files, reducing full-body Java/JNI copies. Compatibility retries have explicit purpose, attempt and size limits.
- Reuse source parsing, resource conversions and checked compilations separately. Release locks during network preparation and recheck source, settings and runtime versions before publishing results.
- Add per-resource timing, attempt and failure diagnostics. Failed downloads or candidates preserve accepted subscription files, references and runtime configuration.
- Remove the subscription certificate-verification bypass. Downloads always verify certificate chains and hostnames; the legacy database column remains compatible without deleting user subscriptions.
- Android versionName is `0.3.109` and versionCode is `187`. No before/after Kitty device benchmark is available for this release. iOS remains deferred with no release asset.
