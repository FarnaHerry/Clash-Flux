# Clash-Flux v0.3.48

## 简体中文

- 修复宽屏首页内核按钮的共享过渡：点击后立即移动到状态卡片中心并展开，停止时反向收回。启动与停止操作仍在点击时开始；加载提示在过渡结束后显示，避免逐帧重绘打断动画。

## English

- Restored the wide Home core button's shared transition: it moves to the status card center and expands immediately on start, then shrinks and returns on stop. The core command still begins on click; the loading indicator appears after the transition so its repaints cannot interrupt the motion.
