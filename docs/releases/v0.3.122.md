## English

- Home proxy group and node pickers combine the search editor and results in one surface. The list adapts to the space above and below while the editor and dashboard cards stay in place. Both pickers remain visible when there are no choices.
- Easter eggs mount on demand. Returning to the front disables the back link immediately and removes it after the fade so front controls receive hover and clicks.
- Update the HuxerUI fork to `21b811e`. The Linux tray requests menu refreshes for changed layouts and avoids redundant icon and tooltip updates.
- Android versionName is 0.3.122 and versionCode is 200.
