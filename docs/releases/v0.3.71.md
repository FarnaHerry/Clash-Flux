# Clash-Flux v0.3.71

## 简体中文

- 统一首页卡片的无边框样式，并补充悬停和点击动效；收紧规则页面列表与上方选择区域的间距，移除重复提示。
- 优化订阅规则集准备：最多并发获取三个资源，支持 ETag/Last-Modified 条件请求，并在校验通过后复用本地快照和部分重复的规则转换结果。
- 修复 Android 规则集下载对 HTTP 304 未修改响应的处理。

## English

- Unify the borderless home card style with hover and press animations. Tighten the rules page spacing and remove redundant hints.
- Improve subscription rule-set preparation with up to three concurrent fetches, ETag/Last-Modified conditional requests, verified local snapshot reuse, and reuse of selected repeated rule conversions.
- Handle HTTP 304 Not Modified responses when downloading rule sets on Android.
