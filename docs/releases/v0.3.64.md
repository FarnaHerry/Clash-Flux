# Clash-Flux v0.3.64

## 简体中文

- 桌面宽屏一级页面改为即时切换；数据尚未就绪时显示加载骨架，数据就绪后直接显示页面。窗口宽窄切换时保留页面状态。
- 移除移动端首页 VPN 猫咪悬浮按钮的蓝色底座和阴影，让猫咪动画直接呈现。

## English

- Desktop wide layouts now switch primary pages immediately. Pages show a loading skeleton only while their initial data is unavailable, and retain state when the window crosses the compact breakpoint.
- Removed the blue background and shadow from the mobile home VPN cat button so the animated cat appears directly.
