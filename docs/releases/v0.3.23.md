# Clash-Flux v0.3.23

## 简体中文

- 无用户可见变化；本版本验证 Windows CI 提速：缓存整个构建树（HuxerUI 框架及其依赖只在 pin/补丁变化时重编）、对检出目录关闭 Defender 实时扫描、ninja 缺失时才安装，并在恢复构建树不兼容时自动清空重配。

## English

- No user-facing changes; this release validates the Windows CI speedups: cache the whole build tree (the HuxerUI framework and its dependencies only rebuild when the pin or patches change), exclude the checkout from Defender realtime scanning, install ninja only when missing, and wipe/reconfigure automatically if a restored build tree is incompatible.
