# Clash-Flux v0.3.23

## 简体中文

- 无用户可见变化；本版本验证 Windows CI 提速：缓存整个构建树（HuxerUI 框架及其依赖只在 pin/补丁变化时重编，测试失败也保存缓存）、对检出目录关闭 Defender 实时扫描、ninja 缺失时才安装，并在恢复构建树不兼容时自动清空重配。
- 修复 Windows 上 test_singbox / test_persistence 的回归失败：测试夹具文件改为二进制写入，避免文本模式把 `\n` 落成 `\r\n` 后与按字节断言不一致（仅测试代码，生产逻辑不变）。

## English

- No user-facing changes; this release validates the Windows CI speedups: cache the whole build tree (the HuxerUI framework and its dependencies only rebuild when the pin or patches change, and the cache is saved even when tests fail), exclude the checkout from Defender realtime scanning, install ninja only when missing, and wipe/reconfigure automatically if a restored build tree is incompatible.
- Fix the Windows-only test_singbox / test_persistence regressions: fixture files are now written in binary mode so `\n` is not translated to `\r\n` and then mismatched by byte-exact assertions (test code only; production logic unchanged).
