# Clash-Flux v0.3.14

## 简体中文

- 修复规则页列表在测量阶段读取组合上下文导致的闪退，保留中英文界面并补充编排控件翻译。
- sing-box 稳定基线升级至 **1.14.2**，桌面二进制与 Android libbox 固定同一源码 revision，并校验来源与摘要。
- 桌面 L3 首阶段：唯一主订阅负责兜底，启用规则引用的 Clash YAML 次订阅按来源参与编排；增加固定规则层级、层内优先级、启停/排序和目标不可用策略。
- 隔离不同来源的同名组/节点，改善代理页、托盘与连接链路的来源显示；候选配置先检查，失败时尝试恢复本进程上一份有效配置。
- 扩展 Clash 协议、DNS、拨号链、逻辑规则和 inline provider 映射；转换差异显式进入保真度报告，支持展开完整明细。
- 使用固定 Glaze 9.0.0 整理运行时 JSON 与内部 policy 边界，连接解码移至任务线程；补充英文 README 与架构、能力和迁移文档。

### 支持边界

手机端保持单活动代理订阅。原生 JSON 次来源、跨来源代理链、对象 UUID、崩溃恢复 journal 和外部 provider 完整下载转换尚未实现；L3 最终架构仍在推进。iOS 保持 TODO，不提供发布包。

## English

- Fix a Rules page crash caused by reading composition state during list measurement; preserve the English/Chinese UI and translate the new routing controls.
- Update the pinned sing-box baseline to **1.14.2**, with matching desktop/Android source revisions and provenance/digest validation.
- Deliver the first desktop L3 stage: one main subscription provides the fallback, while referenced Clash YAML secondary sources participate through enabled rules. Add fixed rule tiers, per-tier priority, enable/reorder controls and explicit unavailable-target policies.
- Isolate identically named groups/nodes across sources, show readable source labels, check candidate configurations before switching and attempt in-process recovery on failure.
- Expand Clash protocol, DNS, dialer-chain, logical-rule and inline-provider mappings, with explicit fidelity records and an expandable report.
- Introduce an isolated Glaze 9.0.0 codec for runtime JSON/internal policies, decode connections on worker threads and add the English README plus architecture/capability/migration documentation.

### Scope

Mobile retains one active proxy subscription. Native JSON secondary sources, cross-source proxy chains, object UUIDs, a crash-recovery journal and full external-provider download/conversion remain unfinished. The final L3 architecture is still in progress. iOS remains TODO and has no release package.
