# Clash-Flux v0.3.40

## 简体中文

- 修复手机端连接页不显示连接：Android 没有 `/connections` WebSocket 推送，连接页此前只在应用启动挂载时读取一次跨进程快照，之后启动代理也不会再刷新，页面永远是空的；现在页面激活期间按 1 秒节拍重读快照、切进页面立即取最新数据，桌面保持推送驱动不变。
- Android 数据面启动后立即连接 libbox 控制通道：状态/连接推送不再依赖打开代理页、测速等路径懒触发，连接快照与首页流量在内核（VPN/常驻无 TUN）启动后即开始更新。
- HuxerUI 框架固定版本升级到 `7abe0fc`：合入 fork 侧 28 个集成提交（macOS 多窗口预览、Linux GTK 多窗口移植、glass/backdrop 材质、Windows 渐变与路径阴影资源复用）；上游官方无新提交。

## English

- Fixed the mobile connections page showing no connections: Android has no `/connections` WebSocket push, so the page only read the cross-process snapshot once at app startup and never refreshed after the proxy started; the page now re-reads the snapshot on a 1 Hz beat while active and picks up the latest data immediately on page entry, while desktop stays push-driven.
- The Android data plane now connects the libbox control channel as soon as it starts: status/connection pushes no longer depend on lazy triggers such as opening the proxy page or running speed tests, so the connections snapshot and home traffic stats begin updating right after the core (VPN or resident no-TUN core) starts.
- The pinned HuxerUI framework is updated to `7abe0fc`: 28 fork-side integration commits (macOS multi-window preview, Linux GTK multi-window port, glass/backdrop materials, Windows gradient and path-shadow resource reuse); upstream official has no new commits.
