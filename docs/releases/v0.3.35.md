# Clash-Flux v0.3.35

## 简体中文

- 订阅卡片的「更新订阅」按钮动画与实际任务同步：刷新进行中显示进度圈并忽略重复点击，任务结束（成功或失败）恢复图标；右键/长按菜单的「更新」入口接入同一忙态，行为一致。
- 选中卡片特效由实心主色铺满改为主题容器淡染底 + 主色描边：订阅卡、代理页节点卡与设置页主题卡统一换新，文字不再整卡反色（改用 on_primary_container 对比）；订阅卡流量进度条随之换回主题色组件。
- 日志页改为最新日志置顶：打开页面第一眼是刚发生的日志，新日志到达时出现在顶部，无需滚动跟随；内部存储与导出/复制保持时间正序。
- Windows 应用卸载同步停止并移除 `ClashFluxService` 服务注册，不再遗留开机自启的孤儿服务；版本升级路径不受影响（服务存活，代理不中断），用户数据依旧保留。

## English

- The subscription card's "update" button animation now tracks the real task: a progress circle shows while the refresh is in flight (duplicate taps ignored) and the icon returns when it finishes, whether it succeeds or fails; the context/long-press menu's update entry shares the same busy state.
- Selected-card styling swaps the solid primary fill for a themed container tint plus a primary border, applied uniformly to subscription cards, proxy node cards and the settings theme cards; text no longer inverts across the whole card (it uses on_primary_container), and the subscription card's traffic bar returns to the themed progress component.
- The logs page now shows the newest entries at the top: the page opens on the latest lines and incoming logs appear at the top without scroll following; internal storage, export and copy keep chronological order.
- Uninstalling the Windows app now stops and removes the `ClashFluxService` registration, leaving no boot-time orphan service behind; the version-upgrade path is unaffected (the service survives and the proxy keeps running) and user data is still preserved.
