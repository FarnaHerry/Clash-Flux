# Clash-Flux v0.3.93

## 简体中文

- 新增 Geo DAT/MMDB 支持：GeoSite/GeoIP DAT 转换为 sing-box 原生 inline rule_set，保留域名匹配类型、双地址族 CIDR 与 `inverse_match`；GEOSITE 支持按一个或两个属性的存在性交集筛选。国家与 ASN MMDB 支持 MaxMind、sing-geoip、Meta 及常见 GeoLite2/DBIP/ipinfo 记录结构，缺失分类、损坏或不支持的数据整份拒绝，不替换为内置 Geo 数据。
- 订阅外部资源页展示实际类型、名称和链接，可单独刷新 HTTP 规则/代理集合及受支持的 Geo DAT/MMDB，并显示 Geo 缓存状态与大小；新增对应的 CLI 只读查询、逐项刷新和到期检查命令。
- HTTP rule/proxy provider 按各自 `interval`、Geo 按 `geo-auto-update` / `geo-update-interval` 独立检查到期。每轮最多处理三项并轮换，失败保留旧缓存和运行配置；停止或未参与的来源只更新缓存，运行中配置字节变化才执行完整候选交接。
- 设置中的「资源」页可管理跨订阅引用的原生 JSON/SRS 规则集，保留稳定 ID、引用详情与受引用删除保护；全局规则和订阅个人规则可直接选择这些资源。本地内容保存前也会经过固定内核候选检查。全局规则编辑草稿可跨页面保留，过期加载或保存不会覆盖更新后的编辑。
- 规则与代理集合共用有界下载协调器，相同完整请求可合并在途传输，各候选仍独立暂存、检查和原子提交；新增分阶段耗时、请求、缓存、字节数及桌面实际建连计数诊断。
- 首页「系统代理」「虚拟网卡」卡片新增独立设置入口：系统代理可配置端口、局域网与环境变量，虚拟网卡可配置 MTU 1280–9000、严格路由与 IPv6；宽屏使用弹窗，Compact 使用二级页。TUN 的界面名称统一为「虚拟网卡」。
- 独立到期调度只在应用 Runtime 存活期间运行，桌面完全退出或 Android UI 进程被回收后暂停。原生 remote rule_set 仍由 sing-box 管理，Android 不开放其手动强制刷新；本版本不承诺多缓存文件崩溃事务或 Android 异步失败完整回滚。
- 修复 Windows 下经管道或文件重定向运行 CLI 时输出被改写到父进程控制台的问题，脚本和自动化测试现在可以可靠读取命令结果。
- 已验证 Linux 桌面主目标与全部测试目标构建、完整 `clashflux-required` 28/28、生产订阅选择回归，以及 Android Debug Java/NDK 构建。未做 Android 真机 VPN、正式签名覆盖安装、Windows/macOS 实机、真实系统代理/TUN 或安装升级/回滚/卸载验收。
- Android versionCode 为 171。

## English

- Added Geo DAT/MMDB support: GeoSite/GeoIP DAT is converted to native sing-box inline rule sets, preserving domain match types, dual-stack CIDRs and `inverse_match`. GEOSITE supports intersection filtering by the presence of one or two attributes. Country and ASN MMDB handles MaxMind, sing-geoip, Meta and common GeoLite2/DBIP/ipinfo record layouts; missing categories and corrupt or unsupported data are rejected as a whole rather than replaced with built-in Geo data.
- The subscription external-resources page now shows actual types, names and links, refreshes individual HTTP rule/proxy providers and supported Geo DAT/MMDB sources, and displays Geo cache validity and size. Matching read-only query, per-resource refresh and due-check CLI commands are included.
- HTTP rule/proxy providers now check their own `interval`, while Geo uses `geo-auto-update` / `geo-update-interval`, independently of subscription refreshes. Each pass handles up to three rotating items and preserves old caches and runtime configuration on failure. Stopped or non-participating sources only update caches; a running configuration goes through full candidate handoff only when its bytes change.
- Settings → Resources manages reusable native JSON/SRS rule sets with stable IDs, reference details and referenced-deletion protection. Global and per-profile rules can select these resources, and local content is checked by the pinned core before it is saved. Global-rule drafts survive navigation, while stale loads or saves cannot overwrite newer edits.
- Rule and proxy providers share a bounded download coordinator. Identical complete requests can share an in-flight transfer while every candidate keeps independent staging, validation and atomic commit. New diagnostics report stage timings, requests, cache results, bytes and measured desktop connections.
- Home System Proxy and Virtual Adapter cards now have separate settings actions: proxy ports, LAN access and environment variables, plus virtual-adapter MTU 1280–9000, strict routing and IPv6. Wide layouts use dialogs and Compact uses secondary pages. TUN is consistently labeled Virtual Adapter in the UI.
- Independent due scheduling runs only while the application Runtime is alive; it pauses after desktop exit or Android UI-process reclamation. Native remote rule sets remain managed by sing-box, with no manual forced refresh on Android. Multi-cache crash transactions and complete Android asynchronous failure rollback are not claimed in this release.
- Fixed Windows CLI output when launched with piped or file-redirected stdio: output is no longer rewritten to the parent console, so scripts and automated tests can reliably read command results.
- Verified Linux desktop and all test-target builds, the complete 28/28 `clashflux-required` suite, the production profile-selection regression, and Android Debug Java/NDK compilation. Android device VPN, signed upgrade installation, Windows/macOS device testing, real system-proxy/TUN behavior, and installer upgrade/rollback/uninstall acceptance were not performed.
- Android versionCode is 171.
