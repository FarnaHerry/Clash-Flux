# Clash-Flux v0.3.31

## 简体中文

- 桌面应用启动后会在后台检查已安装的系统服务，并在内核自启动前同步版本。Windows Program Files 安装可由 LocalSystem 服务安全地更新自身，无需每次请求 UAC；旧服务与便携版仍可从设置手动更新。
- 服务未安装时不会自动安装；自动检查或更新失败会提示并暂停本次内核自启动，保留手动管理入口。

## English

- Desktop startup now checks installed system services in the background and synchronizes versions before core auto-start. A Windows installation under Program Files can be safely updated by its LocalSystem service without a UAC prompt; older services and portable copies can still be updated manually from Settings.
- Missing services are not installed automatically. A failed check or update reports the issue and pauses that startup's core auto-run while keeping manual service management available.
