# Clash-Flux v0.3.100

## 简体中文

- 修复桌面代理页整体测速的显示节奏：桌面 `/proxies` 只在 `history[].time` 返回最近测速时间，而解码器此前只读取 Android 桥提供的数值 `urlTestTime`，导致桌面节点 `testTime` 恒为 0，必须等整组 `/group/{name}/delay` 返回后才一次性显示。
- 现在从 `history.back().time` 解析 RFC3339Nano 为 UTC 纳秒时间戳，`urlTestTime` 存在时仍优先。仍使用内核组批量测速，保留组 URL、内核并发和历史写入顺序；UI 只在批处理期间读取共享快照，节点写入 history 后即完成自己的延迟显示。
- 代理页分组与订阅页类型两组子标签内容改用密集列表留白（`dense_radius` 4pt），与规则页保持一致；修正 v0.3.99 统一使用 `nested_radius` 后这两页子标签下方和底部出现过宽空白。
- 修复网格首尾留白项高度被压到 0 时，虚拟布局沿用整行估算高度、在首张卡片前生成整卡空白的问题；边缘留白项至少保留 0.5pt。
- 新增 `wire_codec` 必跑回归，覆盖桌面 history 字段、Android 数值字段、时区等价和非法时间。
- Android versionName 为 **0.3.100**，versionCode 为 **178**（上一发布 177）；sing-box/libbox 1.14.4 及其它依赖固定版本不变。
- 验证：桌面完整构建、**32/32** 必跑回归通过；Android Debug Java/NDK/APK 构建通过，并以 aapt 核验 versionName/versionCode；Linux X11 640×1400 实窗核验订阅/代理子标签与首卡间距。未做真机、真实 VPN 或正式签名安装验收；发布 APK 签名由标签 CI 按既有证书核验。

## English

- Fix the desktop proxy page's bulk speed-test display cadence: desktop `/proxies` only exposes the latest test time as `history[].time`, while the decoder previously read only the numeric `urlTestTime` supplied by the Android bridge. Desktop nodes therefore kept `testTime` at zero and displayed every result only after the entire `/group/{name}/delay` batch returned.
- The decoder now parses `history.back().time` from RFC3339Nano into a UTC nanosecond timestamp, still preferring `urlTestTime` when present. Bulk testing remains a kernel group request, preserving the group URL, kernel concurrency and history write order; the UI only reads the shared snapshot during the batch and completes each node as soon as its history is written.
- Proxy group tabs and subscription type tabs now use dense-list spacing (`dense_radius`, 4pt), matching the rules page; this removes the oversized gaps below the tabs and at the bottom introduced when v0.3.99 applied `nested_radius` uniformly.
- Fixed the grid's leading/trailing spacer collapsing to zero height: the virtual layout kept the full-row estimate and rendered a phantom card-height blank before the first card. Edge spacers now retain at least 0.5pt.
- Added a required `wire_codec` regression covering the desktop history field, the Android numeric field, equivalent time zones and invalid timestamps.
- Android versionName is **0.3.100**, with versionCode **178** (previous release 177); sing-box/libbox 1.14.4 and other dependency pins are unchanged.
- Verification: the full desktop build and **32/32** required regressions passed. Android Debug Java/NDK/APK builds passed, with the APK versionName/versionCode checked via aapt; a Linux X11 640×1400 window verified the subscription/proxy sub-tab and first-card spacing. Real devices, real VPN and signed installation were not verified in this round; tag CI verifies the release APK signature against the existing certificate.
