## 中文

- 裸节点订阅默认在服务器端解析代理目标域名；需要目标 IP 的规则会按规则条件精细插入本地解析，并保留 CIDR `no-resolve` 语义。可验证的简单规则集合可内联匹配，无法安全转换的规则会记入不支持账本。
- 订阅设置新增可选远程 DoH 与 DNS 覆写开关；旧设置缺少新增字段时仍按默认值读取。
- 订阅下载默认使用 `sing-box` UA，HTTP 403 时依次回退到 `clash.meta` 和 `clash-flux`。
- 订阅响应缓存绑定订阅 ID、URL、请求 UA、来源版本与正文；首轮迁移刷新会完整 GET 后记录校验头。
- 代理节点网格限制虚拟滚动缓存范围，减少宽屏滚动时的卡顿。
- Android versionName 0.3.113、versionCode 191；iOS 继续暂缓，无发布资产。

## English

- Bare node subscriptions now resolve proxy destination domains remotely by default. Local resolution is inserted only when rules need destination IPs, with CIDR `no-resolve` semantics preserved. Verifiable simple rule sets can be matched inline; unsafe conversions are recorded as unsupported.
- Subscription settings add optional remote DoH and a DNS override switch. Older settings without the new fields continue to load with defaults.
- Subscription downloads use the `sing-box` user agent by default, falling back to `clash.meta` and then `clash-flux` after HTTP 403.
- Subscription response caching is bound to subscription ID, URL, request user agent, source version, and body. The first refresh during migration performs a full GET before recording validators.
- The proxy grid bounds its virtual scroll cache to reduce wide-window scrolling stalls.
- Android versionName is 0.3.113 and versionCode is 191. iOS remains deferred without release assets.
