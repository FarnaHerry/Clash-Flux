## English

- Added one-line install and uninstall scripts (`install.sh` and `install.ps1`): `install.sh` handles sudo-free Linux `.tar.gz` installation to `~/.local/share/Clash-Flux` (with `~/.local/bin/clash-flux` symlink, desktop entry, and post-install `PATH` / system-package shadowing detection; `.deb` and `.rpm` packages remain on Releases for manual installation and native in-app updates) and macOS `.dmg` installation; `install.ps1` installs the Windows `.exe` installer by default (`-Passive`/`-Quiet`/`-Prefix`/`-DesktopShortcut`) or optional `-Portable` `.zip` (with Zip Slip/symlink checks); enforced strict SHA-256 verification via `SHA256SUMS.txt` or GitHub Release API digests, published `install.sh`, `install.ps1`, and `SHA256SUMS.txt` in `publish-release`, added the `install_scripts` CTest regression, and updated README and update docs.
- Upgraded theme color persistence to positive integer IDs (`1` = Gemini through `7` for presets, incrementing IDs for new entries) using `ui.theme_color` and `ui.theme_colors` (`id=spec`): editing any preset or custom swatch updates in place without changing its ID or list slot (fixing preset edits jumping to the end), identical color specs can coexist under distinct IDs without deduplication, `readStartupSettings` preloads `ui.theme_colors` for zero-flash first-frame rendering, and unit tests and UI docs were updated accordingly.
- Android versionName is 0.3.140 and versionCode is 217.
