## 中文

- 新增一行安装与卸载脚本（`install.sh` 与 `install.ps1`）：Linux 优先自动识别并安装 DEB / RPM 系统包（兜底支持便携 `.tar.gz`），macOS 支持 `.dmg` 安装，Windows 默认安装 `.exe`（支持 `-Passive` / `-Quiet` / `-Prefix` / `-DesktopShortcut`）并可选 `-Portable` 便携 `.zip`（含 Zip Slip / 符号链接校验）；严格校对 `SHA256SUMS.txt` 或 GitHub Release API 摘要，并在 `publish-release` 自动附带发布 `install.sh`、`install.ps1` 与 `SHA256SUMS.txt`；补充 `install_scripts` 自动化回归及中英文 README / 更新文档说明。
- 主题配色配置升级为正整数 ID 体系：通过 `ui.theme_color`（当前选中 ID，默认 `1` 为 Gemini）与 `ui.theme_colors`（按行保存 `id=spec`，预设 `1`–`7` 依次为 Gemini / 蓝色 / 紫色 / 绿色 / 橙色 / 粉色 / 青色）持久化，支持直接按 ID 原地编辑并保留槽位顺序（修复编辑预设色块保存后跳到末尾的问题），新增配色从当前最大 ID 递增并允许相同色值以不同 ID 共存；`readStartupSettings` 同步预读 `ui.theme_colors` 以保障首帧零闪烁渲染，并同步更新单元测试与 UI 开发文档。
- Android versionName 为 0.3.140，versionCode 为 217。

## English

- Added one-line install and uninstall scripts (`install.sh` for Linux DEB/RPM/portable `.tar.gz` and macOS `.dmg`; `install.ps1` for Windows `.exe` installer with `-Passive`/`-Quiet`/`-Prefix`/`-DesktopShortcut` or `-Portable` `.zip` with Zip Slip/symlink checks): enforced strict SHA-256 verification via `SHA256SUMS.txt` or GitHub Release API digests, published `install.sh`, `install.ps1`, and `SHA256SUMS.txt` in `publish-release`, added the `install_scripts` CTest regression, and updated README and update docs.
- Upgraded theme color persistence to positive integer IDs (`1` = Gemini through `7` for presets, incrementing IDs for new entries) using `ui.theme_color` and `ui.theme_colors` (`id=spec`): editing any preset or custom swatch updates in place without changing its ID or list slot (fixing preset edits jumping to the end), identical color specs can coexist under distinct IDs without deduplication, `readStartupSettings` preloads `ui.theme_colors` for zero-flash first-frame rendering, and unit tests and UI docs were updated accordingly.
- Android versionName is 0.3.140 and versionCode is 217.
