# Clash-Flux v0.3.18

## 简体中文

- 修复严格字段校验导致常见订阅节点全部被跳过的问题。
- 兼容 VLESS 的空值/`none` 加密字段，以及旧版 WebSocket `ws-path`、`ws-headers` 字段。
- 新旧 WebSocket 字段冲突时保留显式新字段，并在保真度账本中标记近似；异常值仍会明确拒绝。

## English

- Fix subscriptions whose common nodes were all skipped by the strict field validation.
- Accept VLESS empty/`none` encryption compatibility fields and legacy WebSocket `ws-path` and `ws-headers` fields.
- When legacy and modern WebSocket fields conflict, keep the explicit modern fields and record an approximation in the fidelity ledger; malformed values remain explicit errors.
