# Clash-Flux v0.3.83

## 简体中文

- 订阅分享：配置卡片右键新增「通过 QRS 码分享」，把完整配置按 QiFi/QRS 多帧二维码循环显示；手机扫码导入会先尝试 QRS 重组，普通单张二维码仍可直接导入。「分享二维码」保留为订阅 URL 单码，并放大二维码窗口。
- 订阅与规则：规则页改为只读，展示当前主订阅的实际规则和已保存全局规则；订阅规则编辑、查看编译配置、编辑信息和编辑文件从卡片右键进入：宽屏弹窗、窄屏二级页。全局规则改由规则页页头的独立二级页管理，并支持显式选择「直连」作为目标。规则集资源库手工编辑入口移除，已有数据和编译兼容保留。
- 外部资源：订阅卡片右键新增「外部资源」，按订阅只读识别 Clash `rule-providers`（HTTP）、`proxy-providers`（HTTP）和 `geox-url` 的地址；不下载、不改写编译或运行语义。
- 订阅下载：桌面、Android 和 iOS 的订阅请求改用 `clash.meta` User-Agent，兼容要求 Clash UA 的订阅源。
- 首页控制：出站模式、系统代理、TUN 与连接/启停状态拆分。切换这些开关不再让猫咪控制卡闪烁或禁用；并发命令仍由单命令槽拒绝。
- 界面细节：宽屏二级页统一复用自定义标题栏；主题模式卡固定宽度；JSON/订阅文档加载不再显示旋转进度圈，行号栏与文本区域同底色。

## English

- Subscription sharing: the profile card context menu now offers Share as QRS, cycling the complete configuration as QiFi/QRS multi-frame QR codes. The mobile scanner first attempts QRS reconstruction and still imports ordinary single QR codes directly. Share QR remains a single subscription-URL code with a larger dialog.
- Subscriptions and rules: the rules page is read-only and shows the current main subscription's effective rules plus saved global rules. Subscription rule editing, compiled-config preview, profile info editing and file editing open from the card context menu as wide-screen dialogs or compact secondary pages. Global rules move to a dedicated secondary page opened from the rules header and support an explicit Direct target. Manual rule-set resource editing is removed; existing data and compilation compatibility remain.
- External resources: the card context menu adds External Resources, a per-subscription read-only inventory of Clash HTTP `rule-providers`, HTTP `proxy-providers` and `geox-url` addresses. Nothing is downloaded and compilation/runtime semantics are unchanged.
- Subscription downloads: desktop, Android and iOS subscription requests now use the `clash.meta` User-Agent for sources that require a Clash identity.
- Home controls: outbound mode, system proxy, TUN and connection/start-stop state are separated. Toggling those switches no longer restarts or disables the cat control card; concurrent commands are still rejected by the single-command slot.
- UI details: wide secondary pages share the custom title bar; theme mode cards use a fixed width; JSON/subscription document loading no longer shows a spinner, and the line-number gutter uses the text-area background.
