# Clash-Flux v0.3.76

## 简体中文

- HuxerUI 升级至 `ce2a6718`：自动主题接入官方窗口外观接口，跟随系统深浅模式变化；手动主题选项保持独立。Windows 安装器使用同一官方主题接口。
- 首页双击彩蛋改为实时内容轻缩放淡入，移除整卡翻转和光照效果。彩蛋从公共池抽取，目前仅保留 HuxerUI 官方作者 FinalScave 的 GitHub 主页。
- Toast 统一改为最多三条的底部纵向堆叠；新提示挤走最早一条，退场结束后补位。点击或触摸可关闭，自动到期及主动关闭都播放退场淡出动画。
- 补充猫咪动作演示实验室，提供八种可重播动作及无代理/数据库副作用的独立预览模式。

## English

- Upgrade HuxerUI to `ce2a6718`. Automatic theme mode now follows system appearance through the official per-window API; explicit light and dark choices remain independent. The Windows installer uses the same official theme API.
- Change dashboard double-click Easter eggs to a light scale-and-fade of live card content, removing the full-card flip and lighting effect. Eggs are selected from a shared pool that currently contains only the HuxerUI creator FinalScave's GitHub profile.
- Limit Toast notifications to three stacked at the bottom. A new message evicts the oldest and takes its place after the exit animation; clicking or tapping dismisses a message, and automatic and manual dismissal both animate out.
- Add a cat motion lab demo with eight replayable actions and a standalone preview that does not affect proxy or database state.
