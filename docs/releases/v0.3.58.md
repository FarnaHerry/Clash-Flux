# Clash-Flux v0.3.58

## 简体中文

- 桌面端启用托盘、打开「启动时隐藏到托盘」且系统托盘可用时，启动后直接驻留托盘；点击托盘图标再打开主窗口。设置页只在托盘启用时显示该开关；托盘关闭时开关按 false 生效并保留历史值，重新启用后恢复读取。
- 无窗口启动期间仍完成持久化初始化、服务版本同步和内核自启；CLI 与订阅链接唤醒继续按各自流程打开隐藏或可见窗口。
- 保留「启动时隐藏到托盘」设置，并让它受托盘开关控制；托盘未启用时不显示该选项，数据库历史值仍保留。
- Android Release APK 由 CI 使用正式发布密钥签名，并校验 v1/v2 签名及正式证书指纹。

## English

- When both the desktop tray and “Start minimized to tray” are enabled and the tray is available, the app starts in the tray and opens its main window when the tray icon is activated. The startup option is shown only while the tray is enabled; disabling the tray makes it effectively false while preserving its saved value for when the tray is re-enabled.
- Persistence initialization, service version synchronization, and configured core startup continue while no window exists. CLI commands and profile-link activations keep their hidden or visible window flows.
- Kept the “Start minimized to tray” setting and made it conditional on the tray setting. Its saved value remains in the database while the tray is disabled.
- CI signs the Android Release APK with the official release key and verifies both v1/v2 signatures and the official certificate fingerprint.
