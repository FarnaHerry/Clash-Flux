## 中文

- 首页「内网 IP」与「网络检测」统一由应用级 `HomeNetworkModel` 管理，移除手动刷新按钮与「检测中…」加载闪烁：未拿到首份结果前使用空白占位，异步刷新期间保留旧值并在新结果返回后原地替换，两张卡片各自独立保持单飞探测（同时最多 1 个在途任务）；首页「当前订阅」卡新增当前实际生效的具体出口节点展示。
- 网站访问测试在保留同源 `/cdn-cgi/trace` 优先识别的基础上，桌面端在 `HEAD` 流打开期间关联本应用内核 `/connections` 的唯一叶子出站，并通过经 mixed 入站的出口回显请求核实命中同一叶子出站后采信国家码（Windows 未接管代理且确认纯直连环境时支持直连出口识别，带 5 分钟缓存与单飞去重）；HTTP `2xx/3xx` 成功但未能确认出口国家时，状态文案改为「可访问」并附来源悬停说明。
- 修复「订阅下载 UA 顺序」与「DNS 设置」的表单排版错位；「DNS 设置」在宽视口改为 `DialogSize::Form` 弹窗，窄屏保留二级页，共用未保存草稿关闭确认。
- 优化代理页大订阅网格与宽屏日志页的滚动性能与可读性：代理节点卡使用有界单行截断绘制缓存（`SingleLineEllipsisLabel`）减少重挂折半测量开销；日志页改用按真实行宽构建并缓存的原生段落布局（`LogParagraph` / `TextLayout`），兼顾长日志虚拟化滚动与多行终端折行排版。
- 全项目未就绪、缺省或未填充数值槽位统一移除横线字符（`—` / `--`），改为空白占位并保留行高与 `value-placeholder` 占位语义，避免加载前后排版跳变。
- Android versionName 0.3.119、versionCode 197；HuxerUI 保持 `d2c9781c`，sing-box/libbox 保持 1.14.4；iOS 继续暂缓，无发布资产。

## English

- Move Home LAN IP and public-IP checks into application-owned `HomeNetworkModel`, remove the manual refresh button and `"Checking…"` flicker: show blank semantic placeholders before initial results, keep prior values visible during async refreshes until replaced in place, and enforce independent single-flight execution per card (`<= 1` task in flight each). The active profile card on Home also displays the currently selected effective outbound node.
- Enhance website access test exit-country detection while keeping same-origin `/cdn-cgi/trace` first: on desktop, correlate the `HEAD` stream while open with Clash-Flux's active kernel `/connections` leaf outbound and confirm country via egress echo through the mixed inbound (plus Windows confirmed pure-direct egress fallback, with a 5-minute cache and per-key single-flight); when HTTP `2xx/3xx` succeeds without a confirmed exit country, show positive `"Reachable"` status with source-specific tooltips.
- Fix form layout issues in subscription UA order and DNS settings; open DNS settings as a `DialogSize::Form` dialog on wide viewports while keeping a secondary page on compact layouts, sharing unsaved-draft close confirmation.
- Improve large-profile Proxies grid and wide-viewport Logs scrolling performance and readability: proxy node tiles use a bounded single-line ellipsis paint cache (`SingleLineEllipsisLabel`), and Logs use width-observed cached native `TextLayout` paragraphs (`LogParagraph`) for virtualized scrolling with multi-line terminal wrapping.
- Replace dash/em-dash placeholders across the UI with blank layout-preserving semantic slots (`PlaceholderSlot` / `PlaceholderText` with `value-placeholder`), avoiding layout jumps before data hydrates.
- Android versionName is 0.3.119 and versionCode is 197. HuxerUI remains pinned to `d2c9781c`, sing-box/libbox remains 1.14.4, and iOS remains deferred without release assets.
