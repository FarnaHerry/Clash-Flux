# Clash-Flux v0.3.34

## 简体中文

- 首页流量统计卡片改为圆环图：上传/下载共用一个圆环，环心显示占比最大一方的百分比（Lib-Charts fork 的 PieChart 新增 `inner_radius` 圆环样式）；内网 IP 卡片移到订阅卡片之后并增加高度。
- 日志页每条日志改为独立密集卡片：6pt 密集圆角档与减半内边距；等级前缀（info/warning/error/debug）按等级着色，与时间戳、消息融为单一段落自然换行。
- 日志行按终端方式填满再断行：URL、selector 名等超长 token 能在分隔符处断开，不再整块挪到下一行导致上一行提前留白（仅影响渲染，导出与复制仍是原始文本）。
- 日志页与连接页内容区左右留白与分页内容对齐（半份卡片间距），移除遗留的 24pt 桌面页边距。
- 代理页节点卡片一行最多 7 个；顶部不再重复出站模式切换，规则/全局/直连统一在首页卡片切换，代理页只跟随当前模式。
- 规则页移除手动刷新按钮，加号常驻且点击直接新建全局路由规则（列表随订阅与策略保存自动重载）。
- 桌面标题栏搜索胶囊占满标题与动作之间的全部剩余空间，窄窗口随标题/动作收敛；浅色模式补描边保证可见。
- 修复响应式断点切换崩溃：带弹窗锚点的动作视图跨 compact 断点结构性替换时，框架的弹窗锚点转移到替换节点而不是中止运行时（含回归测试）。HuxerUI 固定版本升至 `45bd211`（同时带来 Windows 11 自定义标题栏窗口的系统圆角），Lib-Charts 固定版本升至 `8ed3e03`。
- Android 打开应用不再自动启动代理：只拉起常驻内核，TUN 改为用户显式操作（首页悬浮按钮/设置开关/快捷磁贴）或服务按持久化模式回收恢复时启动；设置页 TUN 开关状态随之对齐。

## English

- The home traffic card becomes a donut: upload and download share one ring with the largest share's percentage in the center (the Lib-Charts fork's PieChart gains an `inner_radius` donut style); the LAN IP card moves after the subscription card with an extra row of height.
- Each log entry on the logs page is its own dense card: a 6pt dense corner tier with halved padding; the level prefix (info/warning/error/debug) is color-coded and merged with the timestamp and message into a single wrapping paragraph.
- Log lines fill to the edge before wrapping, terminal-style: long tokens such as URLs and selector names can break at separators instead of moving wholesale to the next line (rendering only; export and copy keep the original text).
- The logs and connections pages align their side gutters with paginated content (half the card spacing), dropping the legacy 24pt desktop page inset.
- The proxies page fits up to seven node cards per row, and no longer duplicates the outbound-mode switch: rule/global/direct is chosen from the home-page card and the proxies page follows.
- The rules page drops its manual refresh button; the persistent add button always creates a new global routing rule (lists reload automatically with subscription and policy saves).
- Desktop title-bar search capsules fill all remaining space between the page title and the actions, converging as windows narrow; a light-mode outline keeps them visible.
- Fixed the responsive breakpoint crash: when an anchored action view is structurally replaced while crossing the compact breakpoint, the framework transfers the presentation anchor to the replacing node instead of aborting the runtime (with a regression test). The pinned HuxerUI moves to `45bd211` (which also restores Windows 11 system-rounded custom title bars) and Lib-Charts to `8ed3e03`.
- Opening the app on Android no longer auto-starts the proxy: only the resident core is ensured, and the tunnel starts on an explicit user action (home floating button, settings switch or quick-settings tile) or the service's persisted-mode reclaim recovery; the settings TUN switch state now matches.
