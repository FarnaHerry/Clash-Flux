# Clash-Flux v0.3.82

## 简体中文

- 修复 Linux 应用内 RPM/DEB 更新时，应用过早退出导致授权或安装失败且没有反馈的问题。现在授权和安装成功后才退出；取消或失败会回到原窗口并显示错误。
- 首次安装或更新 Windows/Linux 内核服务后，默认自动启动待命内核。
- 若连接、TUN 等操作触发服务安装，安装完成后继续执行原操作及其参数。

## English

- Fix Linux in-app DEB/RPM updates exiting before authorization or installation completed. The app now exits only after a successful install; cancellation and failures return to the existing window with an error.
- Start the standby core by default after installing or updating the Windows/Linux core service.
- When a connect or TUN action triggers service installation, resume that original action and its settings afterward.
