# Clash-Flux v0.3.37

## 简体中文

- 日志卡片圆角收紧到 4pt：密集内容档的圆角整体下调，日志行视觉上更贴合金石质感的高密度列表。
- iOS 模拟器编译链修复（非阻塞门禁自 v0.3.29 起持续红灯，本轮补上最后一层）：Libbox 的 Go runtime 需要 libresolv、后台任务保活代码需要 UIKit，两个消费方（主程序与 Packet Tunnel 扩展）已在链接行补齐。

## English

- Log card corners are tightened to 4pt: the dense-content tier radius moves down across the board, making log lines visually fit the high-density list better.
- The final layer of the iOS Simulator build chain is fixed (the advisory gate had been red since v0.3.29): Libbox's Go runtime needs libresolv and its background-task keep-alive code needs UIKit; both consumers (the app and the Packet Tunnel extension) now link them.
