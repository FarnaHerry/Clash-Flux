## 中文

- 将 Gemini 四色主题通用化为支持 1–4 色混合的主题引擎，支持在添加/编辑颜色中混合 1–4 个颜色并实时预览。
- 内置 Gemini 四色主题拆出独立默认预设 ID `gemini`（展示名 `Gemini`），同时恢复单色 `blue`（`蓝色`）预设；全主题统一参考图灰表面色板。
- 多色渐变/描边接入外观预览条、分区标签指示线、分段选择器、首页代理模式选项、顶部搜索聚焦边框、拖拽落点/文件拖入/选择器浮层边框、代理分组折叠选中点、配额条与运行诊断不确定进度条；一级导航图标改由运行期 `VectorAsset` 生成。
- 延迟色阶保持固定 Gemini 四色（绿/蓝/琥珀黄/红），网站测试失败/超时颜色与首页流量图配色同步收口。
- Android versionName 为 0.3.133，versionCode 为 210。

## English

- Generalized the Gemini four-color theme into a 1–4 color mixing theme engine, with 1–4 stop mixing and live preview in the Add/Edit Theme Color editor.
- Separated the built-in Gemini four-color theme into its own default preset ID `gemini` (`Gemini`) and restored the standalone monochrome `blue` (`Blue`) preset; unified reference-gray surface palettes across all themes.
- Extended dynamic multi-color gradients and outlines to theme preview bars, section tab indicators, segmented selectors, home proxy mode choices, focused search bar outline, drag/drop/picker outlines, collapsed proxy group active indicator, quota bars, and the indeterminate diagnostics progress bar; primary navigation icons are now generated dynamically at runtime via `VectorAsset`.
- Kept latency levels fixed on the Gemini four-color scale (green/blue/amber/red), and aligned website test failure/timeout colors and home traffic chart colors.
- Android versionName is 0.3.133 and versionCode is 210.
