# Clash-Flux v0.3.80

## 简体中文

- 桌面内核启动后默认进入待命状态，节点选择与测速仍可用；点击“连接代理”后才开放代理监听并应用已保存的系统代理/TUN 选择。
- “断开连接”会撤销本应用的接管并让内核回到待命，不再把断开代理等同于停止内核。系统代理与 TUN 仍可独立启用。
- 首页连接状态和计时依据实际代理会话；“启动时自动连接”仍可选择启动后直接连接。Android VPN 生命周期保持不变。

## English

- The desktop core now starts in a ready standby state, keeping node selection and latency tests available. Proxy listeners and saved system-proxy/TUN choices are applied only after selecting **Connect Proxy**.
- **Disconnect** releases this app's traffic takeover and returns the core to standby without stopping it. System proxy and TUN can still be enabled independently.
- The home connection state and timer follow the actual proxy session. **Connect on startup** can still be enabled, and the Android VPN lifecycle is unchanged.
