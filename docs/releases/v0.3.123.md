## English

- Add a persistent log level in Settings: Debug, Info, Warning, Error, or Off. It filters new application and core messages entering the unified log while retaining existing history when logging is off.
- Compact Home proxy-group and node pickers now open with one tap without starting text input or a software keyboard; wider layouts retain search. Packaged country flags are consistent across current nodes, suggestions, and proxy tiles, and the wide desktop navigation rail gains localized tooltips.
- Website tests use a heartbeat icon and running waveform, with static rendering while queued, backgrounded, or using reduced motion. Fixed status and timing areas keep cards and the grid stable.
- Improve profile drop-zone outlines and error messages, the selected profile-creation type, and multiline network fields. Home cards no longer scale or shift when pressed.
- Theme changes use the resolved brightness for circular reveal transitions; reselecting the current mode no longer starts a redundant transition.
- Update the pinned HuxerUI revision to `b65ce62`, incorporating the SDK documentation reorganization and custom chrome in the default Windows installer template.
- Fix SweetEditor simdutf import and link-manifest handling for iOS. iOS remains an advisory diagnostic build with no IPA or release asset.
- Android versionName is 0.3.123 and versionCode is 201.
