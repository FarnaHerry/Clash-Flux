# Clash-Flux v0.3.59

## 简体中文

- 修复 Windows 桌面启动时忽略托盘配置、总是隐藏主窗口的问题。只有托盘启用、启动时隐藏开关启用且系统托盘可用时，才会启动到托盘；其它情况显示主窗口。

## English

- Fixed Windows desktop startup ignoring the tray preferences and always hiding the main window. The app now starts in the tray only when the tray is enabled, “Start minimized to tray” is enabled, and a system tray is available; otherwise, it shows the main window.
