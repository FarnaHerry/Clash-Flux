# Clash-Flux v0.3.78

## 简体中文

- 订阅卡现在展示明确的“长期有效”到期状态，并改善了窄屏与桌面布局中的流量、到期和最近更新时间信息。
- 订阅来源地址只显示主机部分，避免在卡片中暴露 URL 中的凭据、路径和查询参数。
- 优化订阅列表加载骨架屏的响应式布局；窄屏运行诊断改为独立页面，保留输入内容并便于查看结果。
- 多个订阅包含同名代理时，显示名称会区分来源，同时保留代理原名及标点。
- 将 HuxerUI 固定版本更新至 `5dd4009a`，同步字体与主题排版能力。

## English

- Subscription cards now show an explicit “Never expires” state and present traffic, expiry, and last-updated information more clearly across compact and desktop layouts.
- Subscription source addresses show only the host, keeping URL credentials, paths, and query parameters out of the cards.
- Improve the responsive loading skeleton for the subscription list. Runtime diagnostics now use a dedicated page on compact screens, preserving the entered target while showing results.
- When multiple subscriptions contain proxies with the same name, qualify the display names by source while preserving the original names and punctuation.
- Update the pinned HuxerUI revision to `5dd4009a` for its font and theme typography support.
