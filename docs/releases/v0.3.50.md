# Clash-Flux v0.3.50

## 简体中文

- 设置页「内核」行与首页运行状态现在会显示内核版本：内核未运行或快照未上报时展示固定 pin 的 "sing-box 1.14.3"。版本唯一来源是内核打包 pin（`CLASHFLUX_SINGBOX_VERSION`），以后升级 sing-box 只改一处，界面标识自动联动。
- Android 后台：物理网络的 DNS 服务器列表变化现在也会更新 libbox 接口并延迟重置旧出站连接（此前只有网络/接口变化才触发）；回调携带的 `LinkProperties` 直接交给 libbox，避免系统同步视图滞后导致读到旧 DNS 列表。

## English

- The Settings "Kernel" row and the Home running status now show the kernel version: when the core is not running or the snapshot has no version yet, they display the pinned "sing-box 1.14.3". The pinned version (`CLASHFLUX_SINGBOX_VERSION`) is the single source, so future sing-box upgrades update the UI label automatically from one place.
- Android background: changes to the physical network's DNS server list now also update the libbox interface and reset stale outbound connections after a short merge delay (previously only network/interface changes did). The `LinkProperties` carried by the callback is handed to libbox directly, so it never reads a stale DNS list from the lagging synchronous view.
