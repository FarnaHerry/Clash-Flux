# Clash-Flux v0.3.51

## 简体中文

- Linux 任务栏图标修复：窗口身份与 `clash-flux.desktop` 正确关联，任务栏与启动器显示应用 Logo，不再显示占位字母。
- 应用图标重制：收紧四周留白、内容放大约 17%，八个尺寸全部以 32 位重导出，Windows/Linux/安装器图标观感更大更清晰。
- 连接列表的「总上传 / 总下载」数字前补上 ↑/↓ 箭头，与速率展示一致。
- 连接详情在宽屏改为从右侧抽屉打开（列表保持挂载、状态保留，Esc/点击外部/系统返回关闭）；窄屏与手机仍进入二级页面。
- 「新建订阅」弹窗重构：移除多余的内外边框与页头按钮，改为标题 + 表单 + 底部「取消 / 创建」，与编辑订阅弹窗同构。
- 修复缺失字符串资源导致的崩溃：悬停复制按钮、打开新建订阅、输入非法订阅链接等路径不再终止进程。
- 设置页「复制环境变量」：下拉固定 220pt 与规则弹窗一致，「复制」改为图标按钮，修复该行溢出容器。
- 输入框全局对齐下拉框：8pt 圆角、48pt 高、14pt 文字、占位符/文字/光标在完整框内居中；订阅与规则表单行间距 12→16pt 更柔和。

## English

- Linux taskbar icon fix: the window identity now matches `clash-flux.desktop`, so the taskbar and launcher show the app logo instead of a fallback letter.
- App icon reworked: tighter padding with ~17% larger artwork, all eight sizes re-exported in 32-bit — bigger and sharper on Windows/Linux/installers.
- The connection list's total upload/download numbers now carry the same ↑/↓ arrows as the rates.
- Connection details open as a right-side drawer on wide screens (the list stays mounted with its state; close via Esc, outside click or system back); narrow windows and mobile still push a secondary page.
- The "New subscription" dialog was reworked: extra borders and the page header are gone — now title + form + bottom "Cancel / Create", matching the edit-subscription dialog.
- Fixed crashes from missing string resources: hovering the copy button, opening the new-subscription dialog, or entering a non-HTTP subscription link no longer terminate the app.
- Settings "Copy environment variables" row: the dropdown is fixed at 220pt to match the rules dialog, "Copy" is now an icon button, and the row no longer overflows its container.
- Input fields globally align with dropdowns: 8pt corner radius, 48pt height, 14pt text, with placeholder/text/caret properly centered in the full box; form row spacing went from 12 to 16pt for a softer rhythm.
