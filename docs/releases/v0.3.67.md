# Clash-Flux v0.3.67

## 简体中文

- 首页取消加载骨架，直接展示固定卡片；尚未就绪的数据使用中性占位值，加载后原位更新。其他页面的卡片、列表和代理页骨架增加统一流光动画，数据就绪后立即切换为真实内容。
- 修正首页流量卡布局，将上传与下载总量移到卡片底部；桌面窄屏与 Compact 首页的猫咪返回动画、运行卡片边框与宽屏行为保持一致。
- Windows `run.ps1` 默认按 CMake 配置的运行时输出目录启动程序，避免误启动过期的根目录可执行文件。

## English

- Removed the loading skeleton from the home page so its fixed cards appear immediately. Unready values use neutral placeholders and update in place; other pages now share a shimmer animation for card, list and proxy skeletons, which disappear as soon as real data is ready.
- Moved total upload and download amounts to the bottom of the home traffic card. Aligned the cat return animation and running-card outline on narrow desktop and Compact home with the wide desktop behavior.
- Updated Windows `run.ps1` to use the CMake-configured runtime output directory by default, avoiding stale executables in the build root.
