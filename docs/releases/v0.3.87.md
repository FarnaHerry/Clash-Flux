# Clash-Flux v0.3.87

## 简体中文

- 修复桌面重启后 sing-box 从内核缓存恢复 `direct`，但应用设置和界面仍显示 `rule` 导致代理全部直连的问题。
- 桌面内核启动、接管或重配后统一协调保存的出站模式：通过 `GET /configs` 回读实际模式，必要时 PATCH，并再次 GET 验证；验证失败按启动失败处理并沿原路径回滚。
- 桌面界面在内核运行时显示实际模式，不再用持久化设置掩盖与内核不一致的状态。
- 增加固定内核运行回归：先在 sing-box `cache.db` 保存 `direct`，再以默认 `rule` 配置重启，确认缓存复现后调用生产协调函数并回读验证为 `rule`。
- Android versionCode 为 165；桌面与 Android 之外的行为不变。

## English

- Fixed a desktop restart issue where sing-box restored `direct` from its kernel cache while the saved setting and UI still showed `rule`, silently sending traffic through the direct outbound.
- Desktop startup, adoption and reconfiguration now reconcile the saved outbound mode through `GET /configs`, patching when needed and confirming with a second GET; failure is treated as a startup failure and rolls back through the existing path.
- Desktop UI now shows the actual running mode instead of masking a runtime mismatch with the persisted setting.
- Added a fixed-kernel runtime regression that seeds `direct` into sing-box `cache.db`, restarts with the default `rule` configuration, invokes the production reconciler and verifies the final mode through a readback.
- Android versionCode is 165; behavior outside desktop and Android is unchanged.
