# Clash-Flux v0.3.69

## 简体中文

- 修复 Windows 安装器在静默安装、卸载及升级调用旧安装器时，因缺少有效窗口句柄而失败的问题。
- 为 Windows 安装器启用新的 Burn 升级标识，避免再次执行存在缺陷的旧缓存安装器；应用仍通过原有 MSI 升级事务更新。
- 安装成功提交后，按产品身份和版本校验迁移清理 0.3.0–0.3.68 的旧 Burn 安装记录及专属缓存。保留用户数据库、订阅、共享 MSI 缓存及其它产品的依赖；未完成的清理记录保留供安装/修复重试。

## English

- Fixed Windows silent installation, uninstallation and embedded upgrade operations failing because the bootstrapper passed an invalid parent window handle to Burn.
- Started a new Burn upgrade lineage to avoid running defective cached installers while retaining transactional upgrades through the existing MSI identity.
- After a successful MSI commit, migrate legacy Burn registrations and private caches for versions 0.3.0–0.3.68 after checking their product identity and version. User databases, subscriptions, shared MSI caches and other products' dependencies are preserved; incomplete cleanup remains registered for a later installation or repair to retry.
