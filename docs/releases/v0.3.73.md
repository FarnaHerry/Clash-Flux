# Clash-Flux v0.3.73

## 简体中文

- 订阅规则页只展示支持规则编辑的来源；工具栏适配中等宽度窗口，手机上的编译 JSON 改为独立页面。
- 更新订阅时不再持有计划生命周期锁等待网络，请求完成后重新核对订阅版本，再原子提交，避免阻塞其它规则和覆盖并发修改。
- 更新某个订阅时仅该来源显示加载骨架；切换来源保留各自规则快照，避免整页一起闪动。
- 跟进 HuxerUI 多窗口 API 变更，托盘唤起与无窗启动为新窗口提供独立的 `AppRoot` 工厂；同步修复 Win32 `CreateWindow` 宏冲突和 macOS 窗口关闭合并回归。
- Linux 安装包构建固定使用经 SHA-256 核验的 patchelf 0.19.2，满足新框架部署检查。

## English

- Show only rule-editable sources on the subscription rules page. The toolbar fits medium-width windows, and compiled JSON opens on its own page on phones.
- Do not hold the plan lifecycle lock while waiting for a subscription download. Recheck the source before atomic commit so network waits do not block other rules or overwrite concurrent edits.
- Show a loading skeleton only for the source being refreshed and keep per-source rule snapshots when switching sources.
- Adapt tray activation and windowless startup to HuxerUI's new multi-window API by providing an independent `AppRoot` factory for each window; include HuxerUI fixes for the Win32 `CreateWindow` macro collision and macOS close regression.
- Pin Linux package builds to patchelf 0.19.2 and verify its SHA-256 to meet the updated framework deployment requirement.
