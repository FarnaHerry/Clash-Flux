## English

- Reduce first-load waiting on the read-only rules page by avoiding repeated full-document parsing and projection.
- Reduce share QR/QPS margins and update QRCode, HuxerUI and related extensions.
- Unify validation and emission for 12 Clash protocols through a typed intermediate model. Add reviewed subsets of SS, VLESS, Trojan, HY2, TUIC, AnyTLS and legacy SS URI formats while retaining VMess JSON support.
- Add input capability consistency checks and real pinned-core forwarding regressions, preserving strict TLS validation, complete-candidate checks and existing data on failure.
- Organize protocol and input code under src/converter as an independently maintainable project within the existing repository, module and build.
- Android versionName is 0.3.111 and versionCode is 189. iOS remains deferred without release assets.
