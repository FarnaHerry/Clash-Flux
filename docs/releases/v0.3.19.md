# Clash-Flux v0.3.19

## 简体中文

- 扩展 Clash YAML 到 sing-box 的转换：支持 Hysteria v1 UDP 子集、SSH 认证/主机公钥子集，以及 Shadowsocks simple-obfs、v2ray-plugin 和 UDP-over-TCP 的已映射选项。
- 支持 AND/OR/NOT 路由条件中的 GEOIP、GEOSITE 和 inline RULE-SET 子集。不能保真表达的字段会明确记账并拒绝整条节点或规则。
- 修复 Hysteria v2 的 `MBps` 带宽被当作 `Mbps` 的单位错误。双认证 SSH 会记录密码与私钥尝试顺序差异；外部私钥路径和空用户名会明确拒绝。
- 加强旧数据库迁移的订阅保留回归：验证多条订阅、稳定 ID、设置、原生配置和被引用文件在迁移并重启后仍存在。升级不得通过删除数据库或订阅文件恢复。

## English

- Expand Clash YAML conversion to sing-box with a Hysteria v1 UDP subset, SSH authentication/host-key support, and mapped Shadowsocks simple-obfs, v2ray-plugin and UDP-over-TCP options.
- Add GEOIP, GEOSITE and inline RULE-SET subsets inside AND/OR/NOT route conditions. Inputs that cannot be preserved are reported and rejected as a whole.
- Fix Hysteria v2 bandwidth parsing so `MBps` is no longer treated as `Mbps`. SSH dual authentication records the password/private-key order difference; external key paths and empty usernames are rejected explicitly.
- Strengthen legacy database migration regression coverage for multiple subscriptions, stable IDs, settings, native configuration and referenced files across migration and restart. Database or subscription files must not be deleted to recover from an upgrade.
