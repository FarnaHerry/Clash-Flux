# Clash-Flux v0.3.77

## 简体中文

- 增加 Windows、Linux（DEB/RPM）和 Android arm64 的应用内更新下载与校验。桌面安装前保存配置并断开代理；Windows 安装需用户确认，Linux 由 Polkit 弹出提权窗口。Android 校验官方签名与版本后交给系统安装器，并保留安装来源授权流程。
- 统一新 GitHub Release 资产名称为 `clash-flux-<版本>-<平台>-<架构>.<格式>`，Windows 安装包改为 `clash-flux-<版本>-windows-x86_64.exe`，应用内升级仍兼容旧安装包名称。
- 支持明文或 Base64 包装的 VMess JSON 节点订阅，保留节点顺序并转换为应用可编译的代理配置；不支持或无效的节点会使候选配置整体失败，避免静默丢节点。
- 将 HuxerUI 固定版本升级至 `b0830285`。

## English

- Add in-app update downloads and validation for Windows, Linux (DEB/RPM), and Android arm64. Desktop installation saves configuration and disconnects the proxy first; Windows asks the user to confirm installation, while Linux uses a Polkit elevation prompt. Android checks the official signing certificate and version before handing the APK to the system installer.
- Standardize new GitHub Release asset names as `clash-flux-<version>-<platform>-<arch>.<format>`. The Windows installer is now `clash-flux-<version>-windows-x86_64.exe`; in-app updates continue to recognize previously published installer names.
- Support plain and Base64-wrapped VMess JSON node subscriptions, preserving node order during conversion. Invalid or unsupported nodes fail the whole candidate so nodes are not silently dropped.
- Update the pinned HuxerUI revision to `b0830285`.
