# 连接到编排规则的追溯

2026-11-05 首批实现：桌面连接详情可显示可验证的编排规则 ID、目标来源和运行计划版本。
本批覆盖用户全局覆盖/来源分流规则及编译器生成的原生内网规则；不将主订阅规则、个人规则、
最终出口或只有相似文本的条件猜测成某个 L3 ID。保真度定位动作及原始订阅规则定位继续待做。

## 身份与运行边界

编译器的 `CompileResult.rulePlan` 是独立元数据：保存规则在最终 route.rules 中的位置、
L3 ID、目标来源 ID/名称和层级，以及出站标签显示目录，不向 sing-box JSON 注入追溯字段。
目标不可用时按实际生成的 UseMain/Direct/Reject 动作记录有效来源，不把已撤出的目标当作实际来源。
禁用规则不占位置；模式规则、前置动作和未标注的主订阅规则仍占真实位置。原配置语义不变。

CoreStore 只在启动确认后的 Ready 边界发布不可变 appliedRulePlan，绑定 runtimeEpoch、
planRevision 和通过鉴权取得的 nativeStartedAt。预览、候选检查、失败准备不替换该计划。
连接链路的名称也读取已接受目录，避免候选预览覆盖正在显示的链路标签。

固定内核 1.14.4 的 `/rules` 按运行顺序返回 type/payload/proxy；`/connections` 的 rule
为完整 payload + ` => ` + action，不提供 L3 ID。生产路径核对完整清单长度，并建立包含
所有规则的描述索引，只有完整描述唯一且位置有编译身份时才关联。重复条件、不同源同名
或内核截断后相同的描述不按第一项匹配；动作文本也必须相同。不能核对的条目保留未关联。

规则清单按接受的计划指针、epoch、revision、原生实例缓存，索引仅构建一次。连接数据使用
两次原生 GetStartedAt 核验之间的最新 REST 快照，不把无实例标记的历史 WebSocket 正文
直接绑定新计划。开始读取及结果发布前核对运行身份，UI 发布还会再次核对；变化则丢弃。
获取密钥和运行快照后释放生命周期锁，网络读取不持有该锁或 UI 线程。

首次核验记录当前全部连接 ID 为历史基线，之后不补绑这些连接；只有核验后出现的新 ID
才参与关联。这样同一内核被接回、来源重命名、JSON 相同但策略身份改变时，都不会将旧
连接重新归给新规则。历史连接显示“历史连接未关联”，不显示猜测的 ID、目标来源或计划版本。
连接详情用 ID + runtimeEpoch 识别会话，跨内核重启不会把复用 ID 当作原连接继续更新。

## 界面与传输

详情复用现有滚动布局，在原生规则正文旁显示追溯状态、目标来源、编排规则 ID 与运行计划
版本。匹配、历史连接、重复描述、未标注规则和暂时无法核验分别显示真实状态；网络或格式
失败不阻断现有连接列表，回落到原 WebSocket 展示并保留未关联状态。相同正文但身份/核验
结果变化也重新投影，不因文本未变而保留旧关联。

只在连接列表/详情消费帧且当前有编排规则时补充核验，不增加应用定时器。各消费者最多一个
在途读取，合并期间的通知而不淘汰正在完成的帧；离开页面或会话变化会使旧发布版本失效。每次成功核验需
两个原生实例查询及一个本地连接快照；新计划额外获取一次规则清单。原生查询单次 500ms，
REST 单次 1s、正文最多 8 MiB；失败不缩短清单后继续关联。未知字段投影与原订阅严格检查
分开，Glaze 仍只进入 wire codec TU。大清单使用缓存索引，避免每连接遍历全部规则。

Android/libbox 当前没有配套 `/rules` 清单及同一实例核验路径，本批显示未关联，不伪造支持。
本批不引入持久数据库/恢复 journal，也不声称能追溯未被内核保留的拒绝流量。

## 回归

`connection_trace_runtime` 使用生产编译器、传输客户端、typed codec 和 Read/Bind/Resolve
路径，启动固定官方内核和回环 SOCKS/回显连接。检查超过 64 KiB 的 1500 条原始规则、
唯一/重复编排规则、新旧连接、完整描述及目标、清单缓存和鉴权；故障回归覆盖格式/数量、
停止/过期计划、读取期间实例变化和旧实例拒绝。`page_transition` 挂载生产追溯组件，验证
宽窄布局中状态文案和身份字段仅在可证明关联时显示。实际结果见[主线状态](l1-l2-l3-status.md)。

与 [rules.go](https://github.com/SagerNet/sing-box/blob/c005f35300ce76427dc285481ec5695f5b179cd2/experimental/clashapi/rules.go)。
